## 2. ERRORS AND WARNINGS

### ⚠️ W-1 — FASTIFY LOGGER DISABLED IN PRODUCTION PATH (Medium)

**File:** `src/server/server.ts:36`, `src/server/index.ts`

```ts
const fastify = Fastify({
  logger: false  // Temporarily disable logging for development
})
```

The comment says "temporarily disable for development" but this code is in the production server
entry point and has been there across multiple releases. With logging disabled, all inbound HTTP
requests are invisible in runtime logs — errors, latency spikes, and abuse patterns leave no trace
unless explicitly caught and re-logged by application code. The DigitalOcean App Platform log
viewer will show no request activity.

**Recommendation:** Enable structured logging in production:
```ts
logger: config.env === 'production' ? { level: 'warn' } : false
```
This keeps dev output clean while restoring warn/error visibility in production.
