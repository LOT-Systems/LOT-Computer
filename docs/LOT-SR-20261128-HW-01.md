## 4. Findings that change the brief

1. **F-1 · Steel blocks Qi charging and Wi-Fi.** The charging coil and antenna go under the front glass, so the device charges face-down. The polished back stays solid.
2. **F-2 · 5.0 mm requires a chip-down board.** That means full FCC/CE radio certification, estimated $10–25k. The pre-certified module version comes out at about 6.0 mm. Decision gate G-1 after EVT.
3. **F-3 · Minimum orders.** Custom thin LiPo cells (MOQ 500+) and some displays/cameras are hard to buy at 100 units.
4. **F-5 · The LOT server has no device API or push system yet.** `device_copy` must be added to `displayableEvents` or it won't show in the Log tab.

## 5. Numbers (estimates, not live quotes)

- Unit cost ≈ **$126** at 100 units, including the LOT puck charger.
- Program total: **$20–25k** (6 mm module) or **$28–45k** (5 mm chip-down).
- Battery ≈ 16 mAh/day → **about 6.5 days** on 110 mAh.
