## KEY ENGINEERING CALLS

```
1. STEEL vs RADIO/Qi : a closed stainless box blocks Wi-Fi and Qi. → Qi charges FACE-DOWN
                       through the glass. Antenna at the glass edge + insulated seam slot.
                       Fallback: the two steel halves act as charge contacts.
2. 5.0 mm            : feasible only with the battery nested beside the PCB (L-shaped
                       board). EVT-2 plans 5.5 mm. Inventor decision D1.
3. DISPLAY           : 1.54" e-paper. Holds "Coffee time!" at 0 W. Pager-grade battery life.
4. AI SENSORS        : BME688 (on-sensor gas-class AI, e.g. "coffee brewing")
                       + LSM6DSOX machine-learning core (double-tap wake).
5. BATTERY           : ≈9.4 mAh/day at 15-min sync → ~8 days on 80 mAh.
                       The server controls next_sync_s.
6. COPY BUTTON       : POST /api/device/v1/copy → Log.create(event 'device_copy') → Log tab.
7. COST              : $117–183 per unit at 100. Pilot total ≈ $19–42k incl. NRE and certification.
```
