## DESIGN (SIMPLEST THING THAT WORKS)

```
ONE TABLE     lot_emails (id, senderId, receiverId, subject, body, readAt, timestamps)
ONE COMMAND   /email to <Name>. <message>      (Log)
ONE INBOX     "MAIL" section at top of Sync     (read · reply · compose)
ONE EVENT     SSE 'email' → addressee only      (live delivery)
ONE COMMUNITY GATE  sender AND recipient must hold a chat tag
                    (Admin / R&D / Usership / Onyx / Legacy), not Suspended.
                    Same gate as Sync chat → Email = Chat's private channel.
```

Subject = first line of body (≤60 chars). No CC/BCC/attachments/folders/threads — deliberately out of scope for v1.

## BEHAVIOR NOTES

```
SAFETY      Nothing is sent while typing. The Log block shows TO / SUBJECT and a SEND button
            (typing triggers elsewhere in Log fire on keystroke; mail must not).
RESOLUTION  "Hitomi" → community members whose first name matches. Zero → 404.
            Several → 409 "add a last name" (e.g. /email to Hitomi Tanaka. …).
PARSING     /email to Hitomi. Hi  ·  /email to Hitomi: Hi  ·  /email to Hitomi Hi
            A 2nd word counts as a last name only when capitalised.
PRIVACY     SSE 'email' event is written only to the addressee's stream.
            Inbox/sent queries are scoped to req.user.
AUDIT       Each send writes Log event 'email_sent' (ids + subject, no body).
LIMITS      body 5000 chars · subject 200 chars · no self-mail.
```
