## 5. 15-MONTH UI REVEAL

Only `MonthlyPulseWidget` is month-aware, and it was dead (fix #3). There is no
registry mapping widgets to a reveal month (grep for month-gating in
`System.tsx`: none; widgets gate on QIE signals/`optimalWidget`, tags, time-of-day).
Proposal: `REVEAL_SCHEDULE: Record<WidgetName, number /*month*/>` in one file,
consumed by `System.tsx`, keyed off `joinedAt` (now available client-side).
Month 0 = Time, Memory, Recipe; build up to the Biofield/Investor set by month 15.
Admin tag bypasses. Not built — schedule content is a product call.

## 7. WIDGET USAGE LOG (NEW)

`src/client/stores/widgetUsage.ts`, hooked into `WidgetErrorBoundary`.
Records `mount` (with ms), `crash`, `retry` per widget name. Local only, no
payload data, 500-entry ring buffer in `localStorage['lot-widget-usage-v1']`,
debounced 2 s writes. Console: `__LOT_WIDGET_LOG__.report()` →
mounts / crashes / retries / slowest mount / last seen per widget;
`.entries()`, `.clear()`.
Scope: covers every widget wrapped in a boundary (17 groups, 52 usages).
Interaction events (button presses) are not logged; cross-user aggregation would
need a server endpoint and an explicit privacy call (S-2).
