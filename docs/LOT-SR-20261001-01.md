# LOT-SR-20261001-01 — LOT® Email v1

**Date:** 2026-10-01 · **Branch:** `claude/determined-turing-cp5tus` · **Stage:** PRODUCT (scheduled session)

## Mission
Simplest LOT® Email: compose in Log with `/email to Hitomi.`, new messages appear in Sync, integrated with Sync chat and Cohort matching (Community).

## Delivered
| Layer | Change |
|---|---|
| DB | `migrations/20260801120000_add-lot-emails.cjs` — table `lot_emails` (sender, receiver, subject, body, readAt) + 2 indexes |
| Model | `src/server/models/lot-email.ts`, registered in `models/index.ts`; types `LotEmail`, `LotEmailEventPayload` in `shared/types` |
| API | `GET /api/emails` (inbox + sent, unread count) · `POST /api/emails` (`to` name or `toUserId`) · `POST /api/emails/:id/read` |
| Realtime | SSE event `lot_email` forwarded **only to the addressee** (`/api/sync`) |
| Log | `/email to NAME. message` (alias `/mail`). Typing `/email` shows a hint; **Ctrl/Cmd+Enter** sends. Status shown in an `EMAIL:` block. Listed in `/system` help |
| Sync | New **MAIL** section above chat: unread count, NEW tag, expand to read (marks read), Reply, inline compose form |
| Community / Cohort | `CohortConnectWidget` member card gets an **Email** button → pre-fills recipient in Sync compose (signal `cohort_email_initiated`) |

## Behaviour & guards
- Recipient lookup: case-insensitive first name or "First Last"; self and `Suspended` users excluded.
- Several matches → HTTP 409 with candidate list (name, city); use full name.
- Limits: body 4000 chars, subject auto = first line (120), 20 emails/hour/sender (in-memory), suspended senders blocked.
- Sending is explicit (Ctrl+Enter) so a half-typed `/email` never fires.
- Syntax note: `/email to Hitomi Tanaka: text` — put punctuation after the name; `/email to Hitomi Meet Friday` reads "Meet" as a last name.
