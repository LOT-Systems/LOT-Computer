## INTAKE
Scheduled task: make the Calendar widget reliable — track time, log to Log, military-grade event notifications, keep UI minimal.

## STATE BEFORE
`CalendarWidget.tsx` stored date-only entries (`calendar_entry` log). No time, no completion state, no alerts, entries had no id.

## RELIABILITY DESIGN
- **Only the highest reached stage fires** per entry — no burst of stale alerts after a closed tab.
- **Dedup is server-backed**: fired stages are read from `calendar_alert` logs (works across devices/reloads) plus an in-session ref against refetch lag.
- Engine waits for logs to be fetched (`isFetched`) — history is never replayed.
- Stale entries (>12 h past) are ignored; done entries never alert.
- Every alert and completion is written to Log (`[ALERT] …`, `[DONE] …`).
