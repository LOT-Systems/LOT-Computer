## INTAKE
Scheduled task: design, develop, deploy the simplest LOT Email system. Compose in Log with `/email to Hitomi`; new mail appears in Sync; integrate with LOT Chat (Sync) and Cohort Dating via LOT Community.

## DESIGN (simplest thing that works)
Email = an existing `direct_messages` row that has a `subject`. No new table, no external SMTP.

```
LOG  /email to Hitomi + body lines
  └─ MailComposer resolves "Hitomi" → member, shows EMAIL: block, SEND →
       └─ POST /api/mail  → direct_messages(subject, message)  + SSE mail_received (id only)
            └─ SYNC: MAIL section above chat (unread underlined, click to open, Reply → /dm/:id)
COMMUNITY / COHORT: "Send message" on a cohort match opens Log prefilled with "/email to <FirstName>"
```

## DECISIONS
- Command must start a line; everything else in the log is the body. After sending, the command line becomes `✉ EMAIL SENT → Name` so it cannot re-fire.
- SSE is broadcast, so `mail_received` carries only `{id, receiverId}` — no content leaks; the receiver refetches the inbox.
- Subject defaults to the first body line (max 200); body max 5000; no self-email.
- Recipient lookup: first/last-name prefix (min 2 chars, 5 results, `%`/`_` stripped). Ambiguous → pick from list.
