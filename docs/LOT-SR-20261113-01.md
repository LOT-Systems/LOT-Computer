## KEY FINDINGS FROM THE SCAN

1. **Paid layout is all-at-once.** `System.tsx` switches from the free layout to the
   full pro layout the moment the `usership` tag lands. There is no Day-1 → Month-12
   path today; the evolution engine is driven by achievements, not Usership tenure.
2. **`MonthlyPulseWidget` already exists** with 12 month messages and a `n / 12`
   counter, but:
   - counts months from `joinedAt` (account activation), not Usership start;
   - stores dismissal in `localStorage`, which breaks the Cross-Device Sync doctrine
     (the pulse reappears on every other device).
3. **Five density tiers already exist** (`breathable → instrument`) — mapped onto the
   year without new CSS.
4. **Style Guide vs. Badges tension.** The Style Guide says "No gamification: no points,
   badges, or leaderboards"; the codex has 812 badges. The design resolves it: month
   seals are records (glyphs), never points, never ranked, never streak-pressured.
5. **Self-care event name drift:** `self_care_complete` (31 uses) and
   `self_care_completed` (21 uses), plus 4 singletons. The seal counter must accept
   both until normalised.
