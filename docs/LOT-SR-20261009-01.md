# LOT-SR-20261009-01 — LOT® EMAIL v1

**Date:** 2026-10-09 · **Branch:** claude/determined-turing-2h1s3o · **Status:** YELLOW — code complete, NOT compiled/tested (no node_modules; npm unreachable in sandbox)

## Brief
Simplest LOT® Email: compose in Log with `/email to Hitomi.`; new messages appear in Sync; tie to Lot Chat (Sync) and Cohort Dating via LOT Community.

## Design
```
LOG  /email to Hitomi. Dinner at 7?   --Ctrl+Enter-->  POST /api/mail
                                                          |
                                      mails table  <------+--> SSE 'mail' (receiver only)
                                                          |
SYNC  EMAIL · N NEW inbox (above chat)  <-----------------+
```
- Syntax: `/email to Name. body` (also `:` `,` `;`). Parser: `src/shared/email-command.ts`.
- Typing `/email` shows `EMAIL: COMPOSE` hint; **Ctrl+Enter** sends (no accidental sends while typing). Result block `EMAIL:` shows SENT / FAILED.
- Recipient resolution (LOT Community): case-insensitive first name or email. Multiple matches → prefer the single member in the sender's city+country (cohort neighbour); otherwise 409 with candidate list (use email).
- Sync: inbox block above chat; click unread to mark read; live refresh via SSE `mail` event (delivered only to receiver). Same Sync access gate as chat.
- Cohort Dating: the same resolver means any cohort match name from the Cohort widget can be mailed by first name; no extra surface added (kept minimal).
