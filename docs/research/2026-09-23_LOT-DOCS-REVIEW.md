own copy of the design system: **`docs/technical/LOT-STYLE-GUIDE.md`**
("LOT Design System & Style Guide," v1.0, Jan 2026, by Vadik Marmeladov).
Key rules documented there:
- Monospace-aesthetic typography; opacity hierarchy (90/60/40 in place of a
  color-based hierarchy).
- Spacing scale: `mb-16` / `mb-12` / `gap-8` / `gap-y-24`.
- "No decorative colors, no emojis, periods over checkmarks."
- Interaction pattern: clickable labels cycle through views; fade timing of
  3s + 1.4s; button groups limited to 2–3, verb-only labels.

This is the closest thing to "brand standards" available without live site
access. It should be treated as **possibly stale** relative to whatever is
currently published at `brand.lot-systems.com` — there's no way to confirm
parity today.
