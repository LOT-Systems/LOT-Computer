## DESIGN

Internal mailbox only (no SMTP, no external deliverability). Separate from
DirectMessage (chat-style, no subject/read state).

```
COMPOSE  : Log  →  "/email to Hitomi. message"  →  Ctrl+Enter (sends instead of save)
           "to" = first name or full name (case-insensitive). Ambiguous → 409 + candidates.
           Log line is replaced with "✉ sent to Hitomi Tanaka" after delivery.
DELIVER  : POST /api/emails  → emails table  → SSE 'email' event (receiver only)
INBOX    : Sync tab, above chat. ● = unread. Click = expand + mark read.
COHORT   : Cohort Connect (LOT Community) match → "Email" button → Sync composer pre-addressed
           (signal cohort_email_initiated). Resolves by userId, no name ambiguity.
CHAT     : Inbox is visible to all members; chat stays gated by existing tags.
LOGGING  : email_sent log event (social-interaction signal), same pattern as direct_message_sent.
```
