## DESIGN — THE SIMPLEST EMAIL

```
LOG  ──  /email to Hitomi. Hello, are you free Friday?
          │  (addressee ends at "." ":" or newline; the rest is the body)
          ▼
   EMAIL block under the log: TO Hitomi Tanaka · body preview · [Send]
          │  POST /api/emails
          ▼
   emails table ──► SSE `email` (receiver's stream only) ──► SYNC › Mail
```

- One table, no subject, no threads, no attachments. Body only (max 5000 chars).
- Internal mail between LOT Community members. It does not use Resend or leave the platform.
- Chat (Sync) stays public. Email is private 1:1 and sits above the chat in the same tab.

## COMMUNITY / COHORT INTEGRATION

- Community gate: sender and recipient must both have a Sync-eligible tag (Usership, Onyx, Legacy, R&D, Admin). This is the same rule as Lot Chat. Suspended users cannot send or receive.
- Name resolution: `/emails/resolve?name=` does a case-insensitive first-name match among eligible users, excluding the sender. If several match, Log shows a picker with city and country.
- Cohort Dating: the Cohort Connect widget's "Send message" button was a dead-end `goTo('sync')`. It now prefills the Sync mail composer with the matched member, and still records `cohort_message_initiated`.
- Privacy: the SSE `email` event is written only to the receiver's stream and carries id, sender name and time, never the body.
