## BUILD — LOT® EMAIL SYSTEM

```
Log command:      /email to <Name> <body>   (also: /mail, ✉️, ✉, 📧)
                   Regex capture: /\/(?:email|mail)\s+to\s+(\S+(?:\s+\S+)?)\s*([\s\S]*)/i
                   New LogTrigger: 'email-compose' (src/client/utils/logTriggers.ts)
                   Inline compose panel in Logs.tsx (body field, Send/Cancel,
                   optimistic status line); added to /system help listing.

Sync integration:  Sync.tsx gains a Chat | Mail tab strip (GhostButton pair).
                   Mail tab renders EmailInbox.tsx (new component): list,
                   expand-to-read, auto-mark-read on open, unread badge count.
                   Existing sseMessages/fetchedMessages merge logic for Chat
                   preserved untouched (this session's master had refactored
                   the raw `messages` state into a derived useMemo since the
                   feature was first built — reconciled onto that, not the
                   other way around).

LOT Chat relation: Chat and Mail are sibling tabs of one Sync surface — no
                   separate "LOT Chat" component exists; that name refers to
                   Sync's existing Chat tab (chat_message / ChatMessage model).

Cohort/Community:  ChatCatalystWidget ("Connect:" cohort-suggestion widget)
                   gains a secondary "✉ Mail" button beside its existing
                   action button, for any suggested cohort member. Clicking
                   it navigates to Log and injects `/email to <Name> ` into
                   the live textarea — reuses the same text-trigger surface
                   rather than a separate compose API.

Real-time:         Server /sync SSE switch gains `case 'lot_mail'`, scoped
                   to the intended recipient only: `if (data.toUserId ===
                   req.user.id) write(...)`. New mail arrives live in the
                   Mail tab and bumps the unread badge without a refetch.

Server API:        POST /api/mail            (toName, body, subject?)
                   GET  /api/mail/inbox
                   GET  /api/mail/unread-count
                   PUT  /api/mail/:id/read
                   Recipient resolved by case-insensitive first/last name
                   match against User (Op.iLike) — 404s with hint "No user
                   named "X" in LOT Community" on miss; self-send blocked.

Persistence:       New Sequelize model LotMail (table lot_mails):
                   id, fromUserId, toUserId, subject?, body, read, timestamps.
                   Migration 20260612120000_add-lot-mail.cjs — createTable +
                   two composite indexes (toUserId+read+createdAt,
                   fromUserId+createdAt). Registered in server/models/index.ts.

Shared types:      LotMail, LotMailRecord, LotMailSyncPayload added to
                   shared/types; SyncEvents.lot_mail wired; MAX_LOT_MAIL_LENGTH
                   (2000) added to shared/constants.
```
