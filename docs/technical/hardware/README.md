# LOT Computer — Hardware Documents

Planning and specification set for the LOT Computer: a 40mm x 40mm
stainless-steel notification device that pairs to lot-systems.com. Intake
from S-2 (Vadik Marmeladov), session `LOT-SR-20260922-*`.

No physical unit exists yet — this is Phase 0 (plan) of the roadmap below.
