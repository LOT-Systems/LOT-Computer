## 4. KEY DECISIONS

| Decision | Choice | Why |
|----------|--------|-----|
| Name | LOT-HW-01 "TILE" | Flat silver square |
| SoC | ESP32-S3-PICO-1 SiP (7 × 7 mm) | Wi-Fi + BLE + camera interface + ESP-DL in the smallest footprint |
| Screen | Sharp LS013B7DH03 1.28" memory LCD | Silver/reflective, always-on at µW, 0.74 mm |
| Camera | Himax HM01B0 | < 2 mW, TinyML-ready, smallest z-height class |
| Weather / AI sensors | BME688 (BME AI-Studio), LSM6DSV16X (MLC) | Off-the-shelf parts with AI built in |
| Wireless charging | NFC-WLC (PTX30W / PTX130W) through the glass face, face-down | Qi does not pass through stainless; keeps the mirror face pure |
| Delivery model | 15-min sync + `fireAt` scheduling | ~15-day battery instead of ~2.5 days always-on |
| Cloud | New `/api/device/*` with per-device bearer tokens | The web app uses browser sessions; a TILE has none |
| Copy → Log | `logs` row, `event = device_copy`, metadata = env snapshot | Appears in the existing Log tab with no new storage |
| Compression | 3 levels: AI one-liner (≤ 64 chars) · compact wire + deflate · per-session digest | Requirement 8 |
