         Integrate with LOT Chat (Sync) and Cohort Dating (LOT Community).
ROUTE  : src/server, src/client, migrations, docs
```

## DESIGN

```
COMPOSE : /email to Hitomi. Dinner at 8? /send        (in any Log entry)
INBOX   : Sync tab → "Email" block above chat (Inbox / Sent, unread ●, Reply)
COMMUNITY: Cohort widget → member card → [Email] → opens Sync composer
          pre-addressed to that member.
```

Why `/send`: Log autosaves on every keystroke, so a half-typed
"/email to H" must never go out. The email is delivered only when the text
ends with `/send`, once per log (`log.metadata.email.id` is the idempotency key).
Log shows live status: `DRAFT → HITOMI · END WITH /send TO DELIVER`, then
`SENT → HITOMI TANAKA` or `NOT SENT — <reason>`.

  utils/logTriggers.ts                               wiring, /system help line

```

Safeguards: recipient resolved by first (or first+last) name, case-insensitive;
ambiguous or unknown names fail visibly rather than guess; suspended users can
neither send nor receive; no self-email; 20 emails/hour/sender; 5000-char body;
a log is only allowed to send mail if its owner is the editor; SSE delivers
email events only to the receiver (unlike chat, which is broadcast).
Sync inbox is visible to every user, including those without chat access.
