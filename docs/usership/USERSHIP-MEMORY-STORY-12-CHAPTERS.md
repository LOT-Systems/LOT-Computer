## 1. DOCTRINE RECONCILIATION

The brief asks for monthly celebration, affirmations, badges and "Months unlocked: 3/12".
LOT-DOCTRINE Revision K says:

```
CLAUSE 6  AMBIENT AI. No congratulatory pop-ups. No progress celebrations.
CLAUSE 9  LONG-TERM SIGNAL. No gamification. No streaks. No leaderboards.
ORDER 8   No superlatives. "Done." not "Amazing job!"
```

Both can hold. The resolution:

```
CELEBRATION = RECOGNITION, NOT REWARD
  1  The month is sealed by time, not earned by score. Nothing can be lost.
     "Months unlocked" is a calendar fact. It is not a streak.
  2  The affirmation is built from evidence. It cites the person's own words and counts.
     "You checked in 22 mornings." It does not say "Great job."
  3  It appears inline in the feed as a Block. No modal, no overlay, no confetti, no sound.
  4  It appears once per month. It fades on completion (3s + 1.4s, Order 5).
  5  The person can dismiss it, keep it, or edit the Chapter. They own it.
```

> Proposed: **Clause 6 amendment — Monthly Seal.** Once per month the system may
> address the person directly, in one Block, with an evidence-backed affirmation.
> This is the only scheduled acknowledgment. (S-2 decision D1.)

## 3. THE CHAPTER — ONE UNIT OF COMPRESSED MEMORY

A **Chapter** is one paragraph that compresses one month of a person's life,
written in second person and in LOT voice. Its shape is fixed, so it reads as a
ritual. Its content is never generic.

```
┌──────────────────────────────────────────────────────────────────────┐
│ CHAPTER 4 · THE PORTRAIT                          Oct 10 → Nov 9     │
│                                                                      │
│ [1 PRESENCE ]  Twenty-six of thirty-one days.                        │
│ [2 SIGNAL   ]  the most-supported pattern, with n of m               │
│ [3 VOICE    ]  one verbatim line from the person's own Log, dated    │
│ [4 TURN     ]  what changed vs last month — a delta, not an adjective│
│ [5 FORWARD  ]  one sentence of self-care direction for next month    │
│                                                                      │
│ COMPRESSED: 118 entries · 31 days → 1 paragraph (46 words)           │
└──────────────────────────────────────────────────────────────────────┘
```

**The COMPRESSED line is what makes it tangible.** Each month the person sees how
much of their life went in, and the line on its own carries the year's story:

```
M1   COMPRESSED:  23 entries · 30 days → 1 paragraph (21 words)
M6   COMPRESSED: 131 entries · 31 days → 1 paragraph (45 words)
M12  COMPRESSED: 2,104 entries · 365 days → 1 paragraph (109 words)
```

### 3.1 Truthfulness contract

```
T1  No count, no claim. Every pattern line carries n of m.
T2  Quotes are verbatim, inside quote marks, with a date. Never paraphrased in quotes.
T3  Sparse month → short Chapter. Never padded. 9 entries yields 2 sentences.
T4  Medical / trauma-flagged entries never quoted (existing LOT_PTSD_Protocol).
T5  The person can Keep · Edit · Delete. A deleted Chapter leaves the ladder.
T6  If the AI provider fails, a deterministic template is built from monthly-summary.ts
    and the Chapter is marked "template". It is regenerated on the next run.
```

## 4. COMPRESSION BUDGET — THE LADDER

Signals flow upward. Every layer is stored and never overwritten, and each layer
cites the one below it.

```
RAW LOG          note · emotional_checkin · answer · plan_set · self_care_complete
   │ nightly     (J-new, 02:00 local)
DAY LINE         1 instrument line (Cockpit Rule)          stored · hidden by default
   │ weekly
WEEK SEAL        1 sentence  · ≤ 18 words                  visible from Day 7
   │ monthly
CHAPTER          1 paragraph · 20–80 words, scales by Act   visible from Month 2
   │ quarterly
ACT SEAL         1 paragraph · 60–80 words · 1–3 quotes      M3 · M6 · M9
   │ yearly
YEAR CODEX       1 annual paragraph · 100–150 words         M12
                 + 12 Chapters + 4 Act Seals + instrument stats
```

**Word budget grows as the system knows more.** The paragraph gets longer and more
specific over the year. This is the second way the person feels the evolution.

| Act | Chapter length | Quotes | Patterns named | Forward line |
|---|---|---|---|---|
| I Observe | 20–35 words | 0–1 | 0 (only counts) | question form ("Mornings next?") |
| II Recognize | 45–55 words | 1 | 1 | suggestion |
| III Anticipate | 50–65 words | 1–2 | 2 | proposed routine |
| IV Guide | 60–80 words | 2 | 2–3 + year arc | direction for next quarter |

### 4.1 Depth signals (what the compression feeds on)

These are the evolutionary signals named in the brief, weighted:

```
SIGNAL        EVENT                   WEIGHT   NOTE
JOURNAL       note                    3        the heaviest; thoughts put into Log
CHECK-IN      emotional_checkin       2        ×1.5 if before 11:00 local (morning)
MEMORY        answer                  2
SELF-CARE     self_care_complete      1        self_care_skip = 0, never negative
PLAN          plan_set                1
DAILY CAP     12 weighted points/day  —        spam cannot inflate depth
```

Monthly Depth Score bands: **SPARSE** 0–29 · **STEADY** 30–89 · **RICH** 90–179 ·
**DENSE** 180+. Depth sets how rich the Chapter is. It never decides whether the
month unlocks.

## 6. DELIVERY CHOREOGRAPHY — THE 72 HOURS AROUND EACH SEAL

The monthly anniversary is counted from **Usership start**, not `joinedAt` (see
§12 D2). The delivery is paced so the person feels it without being interrupted.

```
T-3d   NEXT UNLOCK hint appears in Months Unlocked view 3:
         "Month 5 · The Rhythm · in 3 days."
T-1d   23:00 local  J-new compresses the month → Chapter stored as DRAFT.
T 0    first open of the day:
         1  NEW MONTH block (top of System tab, above Recipe) — §7.1
         2  tap → MEMORY INSIGHT expands with the Chapter paragraph — §7.2
         3  [ Keep ]  [ Edit ]  → Keep seals the Chapter, awards the month badge
            silently (Ambient: the badge appears on profile, no toast)
         4  block fades (3s + 1.4s). Months Unlocked shows N / 12.
T+1d   email: same Chapter text (monthly-summary email reuses the stored Chapter;
       one source of truth). Unopened Chapters are auto-kept at T+7d.
T+2d   new UI piece for the month appears once with a one-line caption:
         "New: Circadian row. Built from 124 entries."
```

**Rules:** one Monthly Seal per month, on one surface at a time. No push notification
unless the person opts in. If the person does not open LOT that day, the Seal waits
for them and does not expire.

## 9. DATA CONTRACT

### 9.1 Table (Sequelize migration, proposal)

```
memory_chapters
  id               uuid  pk
  user_id          uuid  fk users
  kind             enum  week | chapter | act | year
  index            int   week# / month 1..12+ / act 1..4 / year 1..
  period_start     date
  period_end       date
  text             text
  word_count       int
  entry_count      int   (raw logs compressed)
  depth_score      int
  depth_band       enum  sparse | steady | rich | dense
  quotes           jsonb [{ logId, text, date }]      — verbatim, auditable
  stats            jsonb {journal, checkins, morningCheckins, care, answers, plans}
  source           enum  ai | template
  status           enum  draft | kept | edited | deleted
  seen_at          timestamptz                        — replaces localStorage (Order 6)
  created_at / updated_at
  UNIQUE (user_id, kind, index)
```

Users get one new column: `usership_started_at timestamptz`. It is set when the
Usership tag is first applied, and backfilled from the earliest Usership payment or
the tag date.

```

                                       time is 23:00 on T-1d or Sunday 23:00)

  chapter: week seals + raw stats + quotes candidates → chapter
  act    : 3 chapters + raw stats        → act seal
  year   : 12 chapters + 4 acts + stats  → year codex
```

The compile runs one layer at a time, and each layer reads only the layer below
plus the stats. Token cost is bounded: a Chapter prompt is about 1.5k tokens in
all 12 months, whereas re-reading 2,000 raw logs would not be.

### 9.3 Prompt skeleton (Chapter)

```
SYSTEM  You write one paragraph in LOT voice: second person, declarative, no
        superlatives, no exclamation, no emoji. Every claim must use a number
        from STATS or a quote from QUOTES. Do not invent. Max {budget} words.
        Shape: presence · signal (n of m) · one verbatim quote with date ·
        turn vs last month · one forward sentence for self-care.
INPUT   STATS {...}  PREV_CHAPTER_STATS {...}  WEEK_SEALS [4]
        QUOTES [≤5 candidates, flagged entries excluded]  ACT {I..IV}
OUTPUT  { text, usedQuoteIds[] }
CHECK   server verifies every quoted string exists verbatim in a log;
        fails → template fallback (T6).
```
