## 02 // DELIVERABLE

**`docs/usership/LOT-USERSHIP-12-MONTH-EVOLUTION.md`** — *The Twelve Strata v1*

### Core idea

> **Time unlocks the month. Practice decides how deep it goes.**

Each month the user receives:
- **A Stratum:** a sealed Memory compression of that month.
- **An Unlock:** one new widget or capability.
- **A Seal:** one badge.

How long and detailed the Stratum is depends on **Fidelity**, computed from the four
signals:

```
Log (note) 35% · Morning check-ins 25% · Self-care 20% · Memory answers 20%
TRACE (1 sentence) → SKETCH → PORTRAIT (paragraph) → FULL (paragraph + own quote + forward line)
```

### The arc

```
Q1 THE ARRIVAL   M1 SIGNAL · M2 PATTERN · M3 RHYTHM    → Chapter I
Q2 THE PORTRAIT  M4 MIRROR · M5 ROOT · M6 MERIDIAN     → Chapter II + Half-Year Letter
Q3 THE CURRENT   M7 CURRENT · M8 ARCHIVE · M9 ORACLE   → Chapter III + checkable prediction
Q4 THE CODEX     M10 ARCHITECT · M11 CODEX · M12 LOT® AI → Chapter IV + THE CODEX
```

Compression ladder: daily logs become a monthly Stratum, every 3 months the Strata
become a Chapter, at Month 12 the Chapters become the annual Codex, and the Codex
becomes LOT® AI's long-term context.

### Widgets specified

| Widget | Purpose |
|--------|---------|
| Months Widget | "Months unlocked: N/12" + 12-slot fidelity strip; label cycles through Strata, Next, Fidelity |
| New Month card | Extends `MonthlyPulseWidget`: affirmation + sealed Stratum + quote + seal |
| Memory Widget | "Last month, compressed": one-paragraph insight |
| Chapter Card | Full-width, at M3, M6, M9 and M12 |
| Usership Year Plate | On `/u/<user>` at M12 |
| Seal row | On `/u/<user>`, one seal per month |

### Badges proposed

New category `usership_seal`, **+21** (843 → 864): 13 month seals, 4 chapter seals, 4
fidelity seals. Plus 3 secret candidates: `prophet_confirmed`, `own_words`,
`day_one_return`.
