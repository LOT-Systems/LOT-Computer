## 3 — PERFORMANCE ANOMALIES

### 3.1 ToggleSection CSS Animation Anti-Pattern — FIXED ✓

```
SEVERITY : MEDIUM — design quality issue on a world-class designer site
FILE     : src/client/components/ui/ToggleSection.tsx
BEFORE   : max-h-[2000px] / max-h-0 CSS transition
           — animates over a 2000px range regardless of content height
           — opening: nearly instant (content is tiny vs 2000px budget)
           — closing: slow, stutters as 2000→actual-height is instantaneous
           — GPU-hostile: animates a property that triggers layout recalc
AFTER    : ref-based height measurement (useRef + useLayoutEffect)
           — measures actual scrollHeight before transition
           — animates height from exact px to 0 (or 0 to exact px)
           — switches to `height: auto` after open-transition completes
             so content can resize freely without re-measuring
           — smooth, professional, matches high-end design system standards
```

### 4.2 Tag.tsx — `href={null}` Default — FIXED ✓

```
FILE   : src/client/components/ui/Tag.tsx
BEFORE : href = null     ← null is not a valid href value; browsers render
                            <a href="null"> literally
AFTER  : href = undefined ← standard JS optional default; omits the href
                            attribute entirely when not provided
WHY    : The Props type already declares `href?: string` (optional string),
         so undefined is the correct absent-value. Null would serialize
         as the string "null" in the DOM.
```
