## 3. ACTIONS

### 3a. DEFECT FIX — journal blind spot
`/story` now counts `note` **and** `journal` events. Severity: HIGH — the
flagship narrative feature was compressing everything except the journal.

### 3b. Log Compression Engine LCE-1 (new)
`src/shared/utils/logCompression.ts` — pure module shared by client/server/test.
- Rolling windows: day 24h · week 7d · month 30d · year 365d.
- Totals, mood distribution, valence (mood-authoritative, lexicon fallback),
  first-half vs second-half shift, rhythm in operator's own time zone.
- Context aggregation: cities, °C range, weather, moon, zodiac.
- Peaks ▲▼ with context line; spikes (≥2× baseline); follow-up signals.
- Strips slash commands and machine-appended `📖`/`🕯️` paragraphs so the
  machine never compresses its own output.
- Deterministic `localStory()` fallback — no error strings shown to operator.

### 3c. `/story [period]`
- Client parses `/story day|week|month|year` (+ aliases). Default `week`.
- `POST /api/story` accepts `period`, queries only the window (`createdAt ≥`),
  compresses, merges QIE state, calls Together AI with period-scaled token
  budget, persists `generated_story` with full compression + chronicle.
- Render: LCE stat header → story → chapter/rank line.

### 3d. `/system` registry
`LOG_COMMANDS` + `formatSystemHelp()` in `logTriggers.ts`, grouped
NARRATIVE / INTELLIGENCE / SELF-CARE / ENVIRONMENT / NAVIGATION. The SYSTEM:
block renderer was already group-header aware; no UI change required.

### 3e. Arcade — The Chronicle
Each story = one chapter. XP day 1 / week 3 / month 8 / year 30.
Ranks SCRIBE → CHRONICLER (5) → ARCHIVIST (15) → LOREKEEPER (40) →
MYTHWRIGHT (100). No decay, no streak pressure.
