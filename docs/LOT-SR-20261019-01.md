## DESIGN (simplest thing that works)

```
COMPOSE  : Log, first line  `/email to Hitomi`  (body = rest of log)
           one-liner:       `/email to Hitomi. See you Friday`
           full name:       `/email to Hitomi Tanaka: ...`
SEND     : Ctrl/Cmd+Enter only (never while typing — avoids mid-keystroke sends)
RECEIPT  : log text becomes  `✉ SENT → Hitomi` + body; EMAIL: status block shown
RECEIVE  : Sync tab, EMAIL section above the chat; unread first (●), click = read
LIVE     : SSE event `email`, delivered only to the receiver's stream
RESOLVE  : first name (case-insensitive) or first+last; self and Suspended excluded;
           0 matches → 404 message; >1 → 409 "use the full name"
NO       : subjects, attachments, threads, external SMTP — deliberately out of v1
```

## INTEGRATION

```
SYNC / LOT CHAT : inbox renders inside Sync.tsx; shares the existing SSE channel.
                  Members without chat access (non Usership/Onyx/Legacy/R&D/Admin)
                  still see their inbox; chat gate message is kept below it.
                  Sender name links to the profile (/us/u/:id) for Usership/R&D/Admin.
COHORT / COMMUNITY : Cohort Connect widget (cohort-matched members) gets an
                  "Email" button → writes draft `/email to <Name>` to localStorage
                  → opens Log → primary log is pre-filled and focused.
                  Cohort matching is the discovery path; Email is the first-contact path.
EVENT LOG       : `email_sent` log event (metadata: emailId, receiverId) so the
                  intent engine can see social interaction.
```
