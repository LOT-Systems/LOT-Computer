## 3. Key engineering findings

1. **A closed steel body blocks Wi-Fi and Qi.** The front glass window is the RF and charging
   aperture. LD-01 charges face-down on a soft pad, which also keeps the polished back unscratched.
2. **5.0 mm is a stretch.** The Z-stack comes to 6.0 mm at EVT and 4.5–5.0 mm at DVT (flex-rigid
   PCB, 1.6 mm cell).
3. **Pager latency equals the poll interval** (15 min default) on a ~100 mAh cell. A phone BLE relay
   for near-instant delivery is planned for Rev B.
4. **FCC cost avoided:** using the pre-certified ESP32-S3-MINI-1 module means only a Part 15B test
   is needed, not a full intentional-radiator certification.
5. **The server is ready for the device.** The `logs` table, weather, AI engines and scheduled
   proactive jobs already exist. The device API is a small additive route group with Bearer-token auth.
   Copy creates a Log entry with `event: "device_copy"`, so it appears in the Log tab.
