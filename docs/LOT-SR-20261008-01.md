# LOT-SR-20261008-01 — LOT® Email v1

**Date:** 2026-10-08 · **Branch:** `claude/determined-turing-ah18d1` · **Stage:** PRODUCT (unverified in a running app)

## Brief
Simplest LOT® Email: compose in Log with `/email to Hitomi.`, new mail appears in Sync, integrated with Sync chat and Cohort (LOT Community).

## What shipped
| Layer | Change |
|---|---|
| DB | `migrations/20261008120000_add-lot-emails.cjs` — table `lot_emails` (senderId, receiverId, body, readAt) + 2 indexes |
| Model | `src/server/models/lot-email.ts`, registered in `models/index.ts` |
| API | `POST /api/emails` (by `to` first name or exact `toId`), `GET /api/emails` (inbox 50 + unread), `POST /api/emails/read` |
| Realtime | SSE event `email`, forwarded **only to the receiver's** stream |
| Log | `/email to Name. body` (also `:` or newline). **Sent on Ctrl+Enter only** — autosave never sends. Result block `EMAIL:`; listed in `/system` help |
| Sync | Email panel above chat: unread count, last 10 mails, hover marks read, **Reply** inline composer |
| Cohort | Cohort Connect "Send message" → **"Send email"**; opens the Sync composer addressed to that member |

## Rules
- Community only: sender and recipient need Sync tags (Admin/R&D/Usership/Onyx/Legacy); suspended users excluded; no self-mail.
- Name clash (two "Hitomi") → 409 listing full names; use Cohort/Reply (exact id) to disambiguate.
- Body max 2000 chars. Sending writes an `email_sent` log event (no body) for the intent engine.
