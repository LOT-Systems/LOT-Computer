## 3. Findings
1. **The display is now the schedule risk, not the PCB.** DigiKey shows the LS013B7DH03 at 0 stock with a 28-week standard lead time. A 28-week lead from today lands after the planned EVT (W3) and near PVT. Recommendation: source 20 panels now through Future Electronics or Data Modul, and use a Tindie breakout for P1 (added as risk R0).
2. **The TI BQ51050BEVM-764 Qi eval kit is discontinued at RS.** DigiKey still lists it. Buy two now.
3. **The `ESP32-S3-DevKitC-1U-N8R2` is obsolete.** Order the plain `-1-N8R2`.
4. **Deploying this branch runs the migration automatically** (`production:run` → `migrations:up`). It is additive and the routes stay off without the flag, but merging still changes the production schema. That is decision D-6.
5. **Repo gotcha:** `.gitignore` `server/` (meant for build output) also ignores new files under `src/server/`. The two new server files were force-added in a follow-up commit.
6. **Remaining TLS question:** firmware trusts Let's Encrypt only. The live chain of lot-systems.com could not be checked from here.
