# LOT-SR-20261027-CAL-01 — Calendar Widget Session Report

- **Date:** 2026-10-27 · **Branch:** claude/dreamy-babbage-yqqqf8 · **Class:** ENGINEERING (scheduled)

## Scope
Make the Calendar widget a reliable time tracker that logs into Log and raises minimal, military-style alerts.

## Delivered
| Area | Change |
|---|---|
| Time of day | Entries take optional `HH:MM` (accepts `9`, `930`, `9:30`; invalid input highlights the field, nothing is saved). Stored in `calendar_entry` metadata as `time`. |
| Alert engine | `src/client/utils/calendar.ts` (pure, tested). Stages: **T-15** (15 min before), **NOW** (at time), **MISSED** (5 min after). Only the highest reached stage fires; superseded stages are skipped. MISSED is limited to the last 24 h. |
| Reliability | 15 s tick + re-check on tab refocus. Fired alerts are de-duplicated from Log (`calendar_alert` metadata) plus an in-session ref, so reloads/refetches never re-fire. Failed log write releases the guard for retry. |
| Log | New events `calendar_alert` (`[ALERT NOW] CALL 10:00: text`) and `calendar_done` (`[ACK] ...`). Both added to the `/logs` displayable allowlist in `src/server/routes/api.ts`. |
| Notifications | Inline banner above the widget: `T-12M / NOW / MISSED · TYPE HH:MM · text · ACK`. Monochrome (accent opacity/weight only) to keep the minimalist UI. First ACK requests OS notification permission; OS notifications only fire if already granted. |
| Display | Time shown in upcoming list and selected-day list; same-day timed entries leave the list once ACKed. |

## Known limits / next
1. Alerts run only while the app is open (client-side). Closed-tab delivery needs a server job/push — next session candidate.
2. Two simultaneous tabs/devices can race and log the same alert twice before refetch.
3. Entries are identified by `date|time|type|text`; identical duplicates share one ACK. A real `id` per entry would fix this.
4. No edit/delete of entries yet; no recurring entries.
5. `/api/logs` staleTime is 5 min; ACK/alert writes refetch explicitly, but other-device changes lag.
