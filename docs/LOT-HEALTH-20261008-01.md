downstream steps (Get App ID, Trigger rebuild, Verify deployment) from
running.

a weekly forced rebuild since 2026-09-13. Dependency upgrades, cache clears,
and platform-level resets that this weekly cadence provides have been skipped
for approximately 3 weeks.

**Resolution Required:**
1. Rotate DigitalOcean Personal Access Token at cloud.digitalocean.com
2. Update the `DIGITALOCEAN_ACCESS_TOKEN` secret in GitHub repository settings
   → Settings → Secrets and variables → Actions
3. Manually trigger `Weekly Rebuild & Self-Assembly Sync` to confirm fix
