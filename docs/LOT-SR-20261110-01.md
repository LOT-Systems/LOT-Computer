### Functions

| fn | purpose |
|---|---|
| `createBeingProfile` | uniform registers, every source consent = false |
| `canIngest` | **self-only + per-source consent** gate |
| `calibrate` | landed → pull toward used mix; missed → push away; rate decays `0.3/√(1+n/10)` |
| `dominantRegisters` | top-k registers |
| `composeDirective` | system-prompt fragment: honesty clause + registers ≥0.10 + voice |
| `eraseBeingProfile` | right-to-delete → clean zero-consent profile |
