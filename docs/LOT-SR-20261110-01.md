## DESIGN — "simplest possible"

```
No SMTP, no external provider, no subject line, no threads, no attachments.
One message = sender + receiver + body + readAt. Internal to LOT® members.
Subject/threads/outbound SMTP deliberately deferred (see NEXT).
```

```
 LOG  ──/email to Hitomi: text──►  POST /api/emails ──► emails table
                                         │
                                         ├─► SSE 'email' (recipient only)
                                         └─► Log event 'email_sent' (signal record)
 SYNC ◄── GET /api/emails (inbox+sent) ◄─┘      Mail panel above LOT Chat
 COMMUNITY (Cohort Connect) ──[Email]──► Sync Mail panel, pre-addressed (toUserId)
```

### Behaviour
```
RECIPIENT  : matched by first name (exact) or "First Last" prefix, case-insensitive.
             0 matches → 404; >1 → 409 listing candidates ("use first and last name").
             Self-mail and suspended accounts blocked. Body capped at 4000 chars.
SEND       : never on autosave (avoids sending half-typed text) — explicit Ctrl+Enter / button.
PRIVACY    : SSE delivers 'email' only to the receiver's connection; GET returns only
             rows where the caller is sender or receiver.
```
