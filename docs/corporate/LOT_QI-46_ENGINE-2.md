## II. SIGNAL-CALIBRATION — WHERE THE THESIS STANDS NOW

v0.2 §III Layer 1 defines the Calibration Loop as two data streams —
deliberate and passive. This node names what those streams are *for*, in
plain terms, because the phrase used to describe it drifts toward
overclaiming if left unstated: QI·46 does not extract or store a person's
consciousness, memory, or identity. It reads a **signal** — the same
bioelectric/behavioral signal v0.2 already defines (journal tone, session
cadence, consumable feedback, self-reported biofield state) — and calibrates
its *output register* to that signal. The corpus is the subscriber's
pattern of self-expression. The output is a response shaped to land in that
register. Nothing about the subscriber is uploaded; the arc (v0.2 §III Layer
4) is a longitudinal record of *how this person has spoken to the platform*,
not a copy of the person.

**Restated plainly, for the record:**

```
INPUT:   Deliberate signal (journal, ratings, feedback)
       + Passive signal (cadence, reorder velocity, navigation)
PROCESS: Calibration Loop → context vector → QI·46 inference
OUTPUT:  LOT® voice register, tuned to this subscriber's arc —
         warmth, directness, brevity — per v0.2 §III Layer 3 constraints
NOT:     A copy, model, or simulation of the subscriber as a person.
         QI·46 calibrates a *response*, not a *replica*.
```

This distinction is now doctrine (see §III below) — not because the base
spec was wrong, but because "the engine listens to a person's being" is
poetic shorthand (v0.2 §II, §VIII) that must resolve to an engineering
description before Phase 1 fine-tuning begins. The Story Node stays in the
spec as the founding metaphor. The Assembly Manual stays literal.

## III. DOCTRINE CANDIDATE — SIGNAL, NOT REPLICA

Per the LOT-DOCTRINE rule (fold only after 3+ occurrences or 2+ prior
foldings), this is a **candidate** clause, not yet folded — it is the first
time this distinction has been written down. It is recorded here so the
next two times it recurs, it can be folded honestly rather than invented at
fold time.

```
CANDIDATE CLAUSE — SIGNAL-NOT-REPLICA
QI·46's Calibration Loop (v0.2 §III L1) ingests behavioral/expressive
signal to tune output register. It does not model subscriber identity,
memory, or consciousness. Any future phase document that describes the
engine as "knowing," "holding," or "carrying" a subscriber must mean this:
pattern of self-expression, not the person. COSMO® (v0.2 §III L5) is the
standing check on this boundary — an output that implies the engine holds
more than signal is a COSMO® review candidate, not a delivery.
```
