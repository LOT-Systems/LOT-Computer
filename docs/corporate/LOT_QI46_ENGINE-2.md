self-reports, and platform interaction logs. **That corpus does not exist
in this repository and is not fabricated here.** LOT® is pre-revenue on
the Usership model described in the spec; there is no live subscriber base
yet to generate Layer 0 data from.

## IV. CLARIFICATION — WHAT LAYER 1 ACTUALLY MEANS

The base spec's Layer 1 (Calibration Loop) describes personalization from
subscriber signal — journal entries, self-reported biofield states, session
ratings, engagement cadence. In the language of this repository's already
-running system, that signal *does* exist today, under a different name:
the **QIE (Quantum Intention Engine)** — the live pattern-detection
substrate already instrumented across the platform (112+ named patterns,
38 archetypes, per `docs/benchmark/LOT-LEXICON.md`). QI·46's Calibration
Loop, when built, is the productionization of QIE's existing signal
architecture into an inference-time context vector — not a new sensing
system, and not literal biometric or neural extraction. The founding
thesis's language of "listening to the body" is the same metaphor the
CQGS white paper uses for the Quantum Bread Factory: the machine responds
to the person's ordinary, already-instrumented behavioral signal, not to
anything invasive or novel to collect.
