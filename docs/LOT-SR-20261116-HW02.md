## 1. Headline

1. **Sessions were not compounding.** Every daily run since 2026-11-01 started from `master` on a new branch. That makes 15 unmerged branches and 5 product names (Pager, LOT-P1, LOT-01, TILE, SQ-1). This session took the newest and most complete version (SQ-1, branch `45y5w8`) as the canonical base and wrote a ledger of what the other 14 contain (`docs/09-BRANCH-LEDGER.md`). **Merging this branch is the fix (decision D0).**
2. **Device logic is now tested for the first time.** `firmware/src/lot_core.*` holds the device-independent logic in portable C++17, and `firmware/test/run.sh` runs **43/43 passing** with `-Wall -Wextra -Werror` under AddressSanitizer and UndefinedBehaviorSanitizer.
3. **5.0 mm is reachable.** `tools/zstack.py` gives **4.6 mm** for a frame-board layout with a 2.0 mm cell (~107 mAh, ~11 days at a 15-minute sync). The HW-01 stacked layout is what forced 5.5 mm. **Recommendation for D1: 5.0 mm.**

## 5. Not verified / risks

* The Arduino glue in `main.cpp` has never been compiled. The first real compile happens at P1 on a desk with a DevKit, or in a cloud session that allows `*.platformio.org`.
* Three component heights (Qi coil + ferrite, Li-Po pouch, camera) and the Li-Po density (0.06 mAh/mm³) are planning values.
* Whether the e-paper backplane detunes the Qi coil behind it is untested. Check at EVT-1.
* lot-systems.com, brand.lot-systems.com and institute.lot-systems.com were refused by the egress proxy again (3rd run in a row), so the brand and CQGS pages have still not been read.
* Prices and stock are unverified; the BOM links are search URLs.
