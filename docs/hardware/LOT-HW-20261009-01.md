## 1. Product definition
**LOT Computer** — a 40 × 40 mm pocket "pager" made of two polished stainless-steel parts. Face A: camera, small screen, one button. Face B: polished mirror steel. It receives autonomous AI notifications from lot-systems.com (e.g. "Coffee time!"), senses weather/environment, and its button ("Copy") posts a signal back to the **Log tab**. Wireless-charged.

## 3. Architecture
```
 lot-systems.com (Fastify/Sequelize)         LOT Computer (ESP32-S3)
 ┌────────────────────────────┐   HTTPS    ┌────────────────────────┐
 │ AI job -> notification     │──poll/SSE─▶│ WiFi -> screen+haptic  │
 │ /api/device/* (NEW)        │◀───POST────│ button "Copy" -> event │
 │ Log (event=device_copy)    │            │ BME688/UV/IMU -> telem │
 └────────────────────────────┘            └────────────────────────┘
```
Existing repo facts used: `Log` model has `userId, text, event, metadata(JSONB), context`; `/api/logs` only returns events in a `displayableEvents` whitelist (`src/server/routes/api.ts:1082`); `/api/live-message` already exists (GET, text only); all `/api` routes are session-cookie authenticated (`req.user`), so **devices need a new token auth path** — not present today.

## 4. Mechanical & RF — the hard truth
1. **5 mm total thickness is not realistic for v1.** Stack: cover glass 0.5 + display ~1.5–2 + camera module ~3–4 + PCB 0.8 + battery ≥2 + coil/ferrite ~1 + two steel skins ≥0.6 each. Realistic v1: **8–10 mm**. A 5 mm unit needs flex-PCB, bare-die camera, no haptic motor, ~100 mAh cell. Recommendation: build v1 at ~9 mm, and treat 5 mm as v2 with a separate feasibility study.
2. **Stainless steel blocks WiFi/BLE and Qi.** A fully closed metal shell kills both. Solution: a non-metal window (glass/zirconia/PEEK, WIN1) over the antenna and Qi coil, or a slotted/segmented steel edge. Polished side must stay metal (req 17) → put coil+antenna behind the cover-glass face (face A) and charge **screen-down** on the dock, or use a glass insert ring on the mirror side. Prototype both before tooling.
3. Use 316L, mirror-polished (Ra < 0.05 µm). 2 parts: bezel/front + back, laser-welded or screwed (4 × M1.0 hidden under bezel). IP rating: target IPX4 v1.
4. Camera behind cover glass with small aperture; check privacy — add physical shutter or LED indicator (recommended).

Order ~120 PCBs/BOM (20% attrition), PCBWay turnkey SMT; CNC/MIM 316L 120 sets; manual polishing is the cost driver (**ask for a quote with polish spec**). Functional test jig (pogo pads) flashes + tests every unit and writes a serial to the site. Components at risk of shortage: BME688, Qi RX IC, thin LiPo — buy 150 pcs up front.
