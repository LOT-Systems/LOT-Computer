# LOT-HW-05 — Companion Software (flash + pair)
Web tool (Web Serial / esptool-js) hosted under lot-systems.com: flash firmware over pogo/USB-C, write Wi-Fi creds, show pairing code, run self-test (screen, button, sensors, haptic, charge), print result for QA log.
Factory mode: batch of 100, scan serial → write device ID → store pass/fail CSV.
