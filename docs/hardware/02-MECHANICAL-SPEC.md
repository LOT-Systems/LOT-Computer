# HW-02 — Mechanical Spec (Rev A, draft)
- Envelope 40.0 × 40.0 × 5.0 mm (target; see HW-00 §3), corner R2.0, edge chamfer 0.2.
- **Part 1 — Back plate:** 316L, 0.6 mm, mirror (#8) polish, no holes, no markings except optional laser mark on edge.
- **Part 2 — Front frame:** 316L, bead-blast or satin to contrast, recess for cover glass; apertures: screen window ~28×28 mm, camera pinhole Ø1.5, button flex pad; non-metal antenna window (glass/PEEK) ≥ 8×12 mm over module antenna.
- Join: laser seam weld (sealed) *or* 4× M1.2 + gasket (serviceable, preferred for DVT).
- Tolerances ±0.05; surface Ra ≤ 0.05 µm on polished face.
- Environment: IP54 target; no water-immersion claim.
- Marks: LOT®/COSMO® per brand.lot-systems.com (pending access).
