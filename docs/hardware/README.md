# LOT PAGER — Hardware Programme (codename `LOT-P1`)

A 4×4 cm stainless-steel pocket device that receives autonomous AI notifications
("Coffee time!") from lot-systems.com, shows them on a small screen, and sends a
"Copy" button press back to the site's **Log** tab.
