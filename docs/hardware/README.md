# LOT Computer — Hardware (codename **LOT PAGER**)

A 40 × 40 mm stainless-steel pager-computer tied to lot-systems.com. The site (AI) sends short autonomous notifications ("Coffee time!") to a small screen; a **Copy** button sends a signal back to the site's **Log** tab.
