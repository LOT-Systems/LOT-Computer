## 3. Architecture chosen

ESP32-S3 (Wi-Fi + BLE, talks straight to lot-systems.com, no phone app) · Sharp 1.28" Memory LCD (silver, always-on, µW) · Himax HM0360 AI-vision camera · Bosch BME688 weather + AI gas sensor · Bosch BMI270 IMU · TI BQ51050B Qi receiver · 80–120 mAh LiPo · coin ERM pager buzz · PCBWay for PCB, PCBA and stainless CNC.

## 4. Key analysis findings

1. **Steel vs. wireless.** A closed stainless body blocks Qi and Wi-Fi. The plan routes the coil and antenna under the front glass, so the device charges face-down and the mirror back stays pure. This needs **decision D1**.
2. **5.0 mm is reachable only with PCB and battery side by side.** Stacked = 6.0 mm (EVT), side-by-side = 5.0 mm (DVT), with an ~80 mAh cell.
3. **Battery:** about 8.4 mAh/day at a 15 min poll, so about **9 days** per charge (about 16 days at 30 min).
4. **Cost:** landed **$94–163/unit**. 100-unit pilot **≈ $21–42k**, including EVT/DVT and FCC. FCC cost depends on D2 (bare chip vs. module).
5. **Timeline:** earliest realistic pilot is about 24 weeks after S2 starts.

## 5. Connector: verified behaviour

```
yarn build                                → Client build completed · tsc OK (0 errors)
Fastify inject (mocked models):
  POST /api/device/pair                   → token lotd.<user>.<dev>.<secret>
  GET  /api/device/v1/inbox (bad token)   → 401
  POST /api/device/v1/hello               → { ts, w: 900, tz }
  POST /api/device/notify "Coffee time!"  → inbox n:[{t:"Coffee time!", s:"s"}]
  POST /api/device/v1/ack                 → queue 0
  POST /api/device/v1/copy                → Log event device_copy "Coffee time!"
  POST /api/device/v1/telemetry           → stored latest {t,h,p,iaq,b}
  GET  /inbox (empty, 13:00 local)        → autonomous "Lunch. Step away from the screen." s:"n" (once per slot)
```

Not yet tested: a real Postgres DB, the production deploy, or a physical device.
