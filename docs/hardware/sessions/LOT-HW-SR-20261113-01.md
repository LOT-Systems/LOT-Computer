# LOT-HW Session Report — 2026-11-13 · Session 01

**Routine:** LOT Hardware Computer · **Branch:** `claude/brave-lamport-1yiovy` · **Phase:** S0 Concept → done

## 1. What was done

- Read the server code to anchor the device design to the real backend: session-cookie auth
  (`src/server/index.ts`), `Log` model, `POST /api/logs`, the `displayableEvents` allow-list for
  the Log tab, and the existing `generateContextualPrompts()` notice engine.
- Wrote 9 separate documents in `docs/hardware/` (plan, BOM, mechanical, firmware, API
  connector, companion software, roadmap, manufacturing, user manual).
- Built 9 PDF manuals in `docs/hardware/pdf/` with a reproducible script
  (`scripts/hardware/build-manuals.sh`: pandoc + Chromium).

## 2. Key findings

1. **Feasible with off-the-shelf parts.** Core: ESP32-S3-PICO-1, Sharp memory LCD, Himax
   HM0360 camera, Bosch BME688 + BHI260AP (on-sensor AI), TI BQ51050B Qi, ATECC608B identity.
2. **Stainless steel blocks Qi charging and Wi-Fi.** The coil and antenna must sit behind the
   front glass → device charges **screen-down** (D-1 option A), unless a ceramic back insert is accepted.
3. **5 mm is a stretch.** Z-stack = 5.8 mm with an 80 mAh cell (EVT at 6.0 mm). 5.0 mm needs a
   1.0 mm / ~45 mAh custom cell (~13 days battery).
4. **Cost:** ~US$148/unit → ~$14.8 k for 100, + $4–6 k NRE, + $12–20 k radio certification
   (or ~$3 k on a pre-certified module path).
5. **Timeline:** ~6–7 months to 100 shipped units if decisions D-1…D-4 are made now.
6. **Backend gap:** no device auth or device routes exist yet; the spec for `/api/device/*`,
   `devices` + `device_notices` tables and `device_copy` Log events is in doc 05.

## 3. Decisions waiting on the Inventor
