## Quick Start text (draft)
1. Place on charger, front up, until the screen lights.
2. Press and hold the button 5 s. A 6-digit code appears.
3. Enter the code in lot-systems.com Settings > Pair device.
4. Notices arrive on the screen. Press once to Copy; it appears in the Log tab.
