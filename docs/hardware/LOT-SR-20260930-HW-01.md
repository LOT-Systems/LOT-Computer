## 1. Product definition
**LOT PAGER** — a 40×40×5 mm stainless-steel pocket pager tied to LOT. The AI site pushes short autonomous notifications ("Coffee time!") to its screen; one button, **COPY**, sends a signal back that appears in the site's **Log** tab.

## 2. Architecture
```
LOT AI jobs ──► device_notifications (new table) ──► GET /api/device/inbox ──► PAGER screen + buzz
PAGER [COPY] ──► POST /api/device/event ──► Log(event=device_copy) ──► Log tab
PAGER sensors ──► POST /api/device/telemetry ──► Log/weather context
```
Repo facts used: `Log` model (event/text/metadata JSONB), `GET /api/logs` allow-list, scheduled jobs in `src/server/scheduled-jobs.ts`. No device auth exists today — session-cookie only — so a new device-token layer is required.

## 7. Decisions needed (blocking)
1. **Qi vs stainless:** metal back blocks Qi. Approve non-metal inlay window (recommended) or pogo/magnetic charging.
2. **5 mm thickness:** accept 5–6.5 mm, or drop camera/battery size?
3. **"Made in the USA":** PCBWay builds in China — don't engrave that unless final assembly is US.
4. **Camera privacy:** capture only on-demand with visible indicator? (recommended)
