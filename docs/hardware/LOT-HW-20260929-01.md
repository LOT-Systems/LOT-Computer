## 1. Product definition

**LOT Computer** — a 40 × 40 × 5 mm silver square. A pager for an AI: the LOT site decides, the object tells you.

| Face | Content |
|---|---|
| **Back** | Polished stainless steel (316L), mirror finish. Qi wireless charging through a non-metal window (see risk R1). |
| **Front** | Camera, small screen, one button ("Copy"). |

**Behaviour**
1. Site (LOT AI) pushes a notification → screen shows e.g. `Coffee time!` + haptic/buzz.
2. Button press = **Copy** → device POSTs a signal to the LOT API → appears in the **Log tab** on lot-systems.com.
3. Camera captures on demand; frames are compressed on-device and sent to the LOT API.
4. Weather/environment sensor readings ride along with each signal.
5. Session data compressed (delta + zstd) before upload — mirrors the Memory Engine compression principle in `docs/technical/MEMORY-ENGINE-COMPRESSION-ARCHITECTURE.md`.

**Geometry decision (#3 vs #4):** two stainless shells (front bezel + back plate) laser-welded/snap-fit, final envelope **40 × 40 × 5 mm**. Tight — see R2. Fallback envelope: 40 × 40 × 8 mm.

## 2. Architecture

```
 lot-systems.com (LOT AI, Log tab)
        ▲  │ HTTPS (TLS 1.3)
   POST /api/device/signal   │ GET/WS /api/device/inbox
        │  ▼
 ┌──────────── LOT COMPUTER ────────────┐
 │ ESP32-S3 (Wi-Fi/BLE) + 8MB PSRAM     │
 │  ├ 1.3" IPS / 1.12" OLED (SPI)       │
 │  ├ OV2640/OV5640-class camera (DVP)  │
 │  ├ 1 tactile button (GPIO, wake)     │
 │  ├ BME280/BME680 env sensor (I²C)    │
 │  ├ LiPo 150–250 mAh + BQ25120-class  │
 │  └ Qi Rx coil + Rx IC (e.g. BQ51003) │
 └──────────────────────────────────────┘
```

**LOT API connector** (new; nothing device-specific exists in the repo yet — `src/server/routes/api.ts` has `/logs` for the Log tab, `os-api.ts` has `/os/*` read endpoints):
- `POST /api/device/signal` `{deviceId, type:"copy"|"sensor"|"frame", ts, payload}` → writes a Log entry.
- `GET /api/device/inbox` (long-poll/SSE) → pending notifications `{id, text, ttl}`.
- Auth: per-device token issued at pairing (QR on the site), stored in ESP32 flash-encrypted NVS; revocable from the site.

## 7. Risks

- **R1 Steel blocks Qi and Wi-Fi.** A polished steel back plate shields the coil and antenna. Fix: non-metal window/ring (PEEK/ceramic) behind which the Rx coil sits, antenna on a plastic/ceramic/sapphire face; validate in P2 *before* PCB v1. Highest risk.
- **R2 5 mm thickness.** Camera + LiPo + PCB + Qi ferrite + 2 shells is very tight. Expect 7–9 mm realistically; decide by P2.
- **R3 Battery life.** Camera + Wi-Fi at 200 mAh → deep-sleep + button/BLE wake, poll every N min. Set expectations: days, not weeks.
- **R4 Certification cost/time** (P5) is the usual schedule killer.
- **R5 Privacy.** A camera on a personal AI device: hardware LED, explicit capture only, on-device compression, no background capture.
- **R6 Lithium-battery shipping** (UN38.3) for the 100-unit run.
