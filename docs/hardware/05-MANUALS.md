# LOT COMPUTER — User Manual (draft)

Doc ID: LOT-HW-05 · Rev A · 2026-10-20 · Draft; features marked ★ depend on unbuilt server endpoints.

## 1. In the box
LOT Computer, Qi charging pad, USB-C cable, quick-start card.

## 2. First start
1. Charge: place the polished side *down* on the pad (the charging window is on the mirror side). Full charge ≈ 2 h.
2. On lot-systems.com open Settings → Pair device ★ and read the 6-digit code.
3. Hold the button 5 s; the screen shows "Pair". Enter the code via the setup page or the `lot-device` tool.

## 3. Daily use
- A message appears, e.g. **Coffee time!** The LED pulses once.
- Press the button once: **Copy** — the text is logged to the Log tab ★.
- Press again: dismiss.
- Hold 1.5 s: takes a photo (LED on) ★.

## 4. Care & safety
Do not use near strong magnets for first-aid devices. Do not submerge (IP54). Battery: Li-polymer — do not puncture or heat above 60 °C. FCC/CE testing is required before sale (not yet done).

## 5. Troubleshooting
No notifications: check Wi-Fi, re-pair. Not charging: ensure the mirror side is on the pad, remove metal objects between.

## 6. Privacy
Camera only runs on long-press. Photos upload only to your LOT account.
