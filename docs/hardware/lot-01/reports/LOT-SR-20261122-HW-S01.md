## 2. Key findings
1. **Steel vs. radio and induction.** A sealed stainless case blocks Wi-Fi and Qi. All electrical openings (glass, antenna, coil) go on side B, and the device charges face-down. This is the main architectural decision and must be validated on the bench in P1.
2. **5 mm is achievable only side-by-side.** Battery (2.2 mm), camera (through a PCB cut-out) and ICs share one layer behind a 0.4 mm PCB. The stack is 4.89 mm.
3. **Certification is more than the parts.** FCC/CE for a bare-chip radio costs ~$12–20k against ~$13–16k of build cost for 110 units. Decision D-1/D-5.
4. **The software loop needs no new hardware to prove.** The existing `logs` table (`event:'note'`) already feeds the Log tab, so Copy needs no client change.
5. **Auth boundary.** `/api` requires a session cookie (`server.ts`), so the device API must live at its own prefix `/device-api/v1` with bearer tokens.
