## 1. Product definition — "LOT Pager" (working name)

A 40 × 40 mm, ~15 mm thick desk object. Two stainless-steel shells (brief items 3, 17):

- **Back / polished side:** mirror 316L stainless, plain, with the Qi coil behind it (see risk R1).
- **Front / working side:** square screen, camera, one button ("COPY"), weather sensor vent.
- **Flat silver square (items 4):** read as the 40 × 40 mm × 5 mm silver slab = the charging puck/dock (a 5 mm flat silver wireless charger pad). The device itself is thicker. *Confirm this interpretation.*

Behaviour:
1. Site (lot-systems.com, AI-driven) decides on a notification, e.g. "Coffee time!". Device polls/receives it, shows it on the screen, buzzes (pager feel).
2. Button "COPY" press → device POSTs a signal to the site → appears in the **Log** tab.
3. Camera captures stills on demand; weather sensor reports T/RH/pressure to the site.

## 2. Architecture

```
 lot-systems.com (AI) ──push/poll──► LOT Pager (ESP32-S3) ──► screen/haptic
        ▲                                   │ button, camera, BME280/VOC
        └────── POST /api/device/* ◄────────┘   (Log tab entry)
```

**Existing server hooks (this repo):** `GET /api/live-message` (public text), `GET /api/weather`, `GET/POST /api/logs`, `LogEvent` type (`src/shared/types`), OS API `/api/os/status`. Session auth is cookie-based → unsuitable for a device.

**New server work (LOT API connector, item 6):**
| Endpoint | Purpose |
|---|---|
| `POST /api/device/pair` | one-time code → per-device token |
| `GET /api/device/inbox?since=` | long-poll notifications (`{id,text,ttl,haptic}`) |
| `POST /api/device/event` | `{type:"copy"\|"sensor"\|"photo", ts, payload}` → writes `Log` row, new `LogEvent` `'device_copy'` |
| `POST /api/device/photo` | multipart JPEG, size-capped |
Use hashed bearer tokens, rate limiting, HTTPS only, revocation in settings. Reuse `Log` model so Log tab shows events with no UI rewrite beyond a device badge.

## 6. Risks

- **R1 Qi through steel** — highest risk. Mitigate: charging side uses thin non-metal/ceramic window or polished side is the *front rim only*; test coupons in P0.
- **R2 Certification** — FCC Part 15/CE RED; Qi optional WPC listing. Budget $8–20k and use pre-certified ESP32 module.
- **R3 Polished 316L cost/scratch** — specify PVD or accept finish variance; MOQ at 100 is CNC-priced.
- **R4 Camera privacy** — hardware shutter or LED + explicit capture only.
- **R5 Thermal/battery** — 5 mm thin puck and 400 mAh cell limit peak Wi-Fi duty; use deep-sleep + polling interval ≥30 s.
