# LOT-SR-20261004-01 — LOT® EMAIL v1

DATE 2026-10-04 · BRANCH claude/determined-turing-pvr3cv · STAGE PRODUCT · STATUS GREEN (client build + typecheck delta 0)

## MISSION
Simplest LOT® Email: compose in **Log** with `/email to Hitomi.`, new mail appears in **Sync**, integrated with LOT Community (Sync chat access gate) and Cohort matching.

## DESIGN (LOT style: one primitive, no new screens)
| Piece | Decision |
|---|---|
| Compose | Log slash command `/email to <Name>` — rest of log is the message; first line = subject |
| Recipient | Live lookup of LOT Community members by first/last-name prefix; picks automatically if unique, chips if ambiguous |
| Send | `SEND` button in an `EMAIL:` block under the log. Command is replaced by `✉ SENT TO NAME` (no double send; log keeps the record) |
| Inbox | Top of **Sync**: `EMAIL · N new`, click to open (marks read), live refresh via SSE |
| Community | Sender and recipient must both hold Sync tags (Admin/R&D/Usership/Onyx/Legacy), not suspended |
| Cohort | Cohort Connect widget button is now `Email`: queues `/email to <First>` in Log |
| Privacy | SSE `email` event is delivered only to the addressee and carries metadata only (no body) |
| Abuse | 20 emails/hour/sender, 5000-char body, 120-char subject, no self-mail |
