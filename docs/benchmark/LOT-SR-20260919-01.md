What changed, functionally:
- Live HH:mm:ss clock (1s tick) with T-minus/T-plus countdown to the next
  timed event, rendered above the Add-date button.
- Calendar entries gained an optional HH:MM time field (input type="time",
  clearly marked "time optional" — untimed entries keep the old all-day
  behavior).
- Status escalation per entry: EXECUTE (<=15min) -> ALERT (<=60min) ->
  STANDBY (<=24h) -> ELAPSED, computed from `now` each render.
- "Today" panel above the calendar grid lists today's entries with live
  per-entry countdowns and status coloring (opacity ramps with urgency —
  no new colors, no icons, consistent with existing accent-only palette).
- Fixed-position alert overlay (bottom-right, `grid-fill` texture matching
  MicroCalculator/Planner widgets) fires once per timed entry as it crosses
  the 60-minute horizon, labeled CAL [EXECUTE] / CAL [ALERT], auto-dismisses
  after 30s or on manual ACK. A ref-backed dedup set stops repeat fires.
- Logs.tsx CAL renderer upgraded from entryType+date only to the full
  text + date + time + SCHEDULED/ELAPSED status block — entries now read
  the same in the Log stream as they do in the widget.
- No change to signal wiring: recordCalendarSignal(entryType, date) still
  fires on entry creation exactly as it did before this session (Pattern 26
  `calendar-gap` and SIGNAL_MAP `calendar_entry -> calendar` untouched).
