05a // CHANGE DETAIL
--------------------------------------------------------------------------------
migrations + models:
  lot_mails table: id, fromUserId/toUserId (FK->users, CASCADE), subject
  (nullable), body, read (bool), timestamps. Indexes on (toUserId, read,
  createdAt) and (fromUserId, createdAt) — inbox and sent-history reads
  are both index-covered.

src/server/routes/api.ts:
  POST /api/mail        — resolves recipient by first/last name (Op.iLike,
                           same pattern as admin-api user search); rejects
                           unknown name or self-send; creates LotMail row;
                           sync.emit('lot_mail', ...); mirrors to Log
                           (event: 'lot_mail_sent') on process.nextTick,
                           matching the direct-message logging convention.
  GET  /api/mail/inbox         — last 50, newest first, sender names joined.
  GET  /api/mail/unread-count  — badge count.
  PUT  /api/mail/:id/read      — marks read (scoped to req.user.id).
  SSE switch: added case 'lot_mail' — writes only to the matching
  toUserId, mirroring the existing chat_message_like / settings_updated
  per-recipient filtering already on that socket.

src/client/utils/logTriggers.ts + Logs.tsx:
  New 'email-compose' trigger: keywords "email"/"mail" (no emoji — LOT
  style guide is explicit that emoji are opt-in, not default chrome).
  NoteEditor parses "/email to <name> <message>", opens an inline
  "MAIL:" Block with a resizable textarea + Send/Cancel, using the same
  local-state pattern as the existing /qi, /prayer, /story panels.
  /system help list gained one line.

src/client/components/Sync.tsx:
  Chat | Mail tab strip (GhostButton, opacity-driven active state — no
  new color). Mail tab is open to every signed-in member; Chat keeps its
  existing Usership/Onyx/Legacy/R&D/Admin gate, now scoped to the Chat
  pane only instead of hiding the whole Sync surface. New SSE listener
  for 'lot_mail' feeds EmailInbox live-arrival state without a refetch.

src/client/components/EmailInbox.tsx:
  Inbox list — sender, subject-or-preview, relative time; click to
  expand full body and mark read. No unread visual beyond a bold sender
  line — no color, per style guide's opacity-hierarchy rule.

src/client/components/CohortConnectWidget.tsx (LOT Community) +
ChatCatalystWidget.tsx (cohort nudges):
  "Send message" (Cohort Connect) and a new "Mail" button (Chat
  Catalyst) now navigate to Log and pre-fill "/email to <Name> " in the
  compose textarea via the native-setter trick (required because
  ResizibleGhostInput is a fully controlled React input — a plain
  ta.value assignment would not register). This is the Cohort
  Dating -> LOT Community -> Mail integration path: a cohort match is
  one click from a mail compose addressed to them by name.
