01 // MISSION
Design, develop, deploy the simplest LOT® Email system in LOT® style.
  - Compose in Log:  "/email to Hitomi. <message>"
  - New mail appears in Sync
  - Integrates with LOT Chat (Sync) and Cohort Dating via LOT Community

02 // DESIGN (simplest thing that works)
  - ONE table `emails` (from, to, body, readAt). No subject, no attachments,
    no SMTP — internal LOT mail only. Separate from `direct_messages`
    (which had no migration and no SSE forwarding, so it was unusable as-is).
  - Gate = same as Sync chat: Admin / R&D / Usership / Onyx / Legacy,
    not Suspended. Sender AND recipient must both be Community members.
  - Recipient by first name (case-insensitive). Ambiguous name -> 409 with
    candidates; unknown / non-community -> 404.
  - Delivery: private SSE event `email`, forwarded only to the recipient's
    stream. Sync refetches the mailbox on that event.
