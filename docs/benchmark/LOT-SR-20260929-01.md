00 // BRIEF
Design, develop, deploy the simplest LOT Email in LOT style.
  - Compose in Log:  "/email to Hitomi."
  - New messages appear in Sync.
  - Integrate with LOT Chat (Sync) and Cohort Dating via LOT Community.

01 // DESIGN (SMALLEST THING THAT WORKS)
  - One table `emails` (id, senderId, receiverId, body, readAt, timestamps).
    No subject, no threads, no attachments, no external SMTP: LOT Email is
    internal, member-to-member.
  - COMPOSE (Log): typing "/email to NAME" anywhere in an entry shows an
    EMAIL: block (TO NAME [Send]). The REST of the entry is the body.
    "Hitomi_Tanaka" disambiguates a two-word name. On send the command is
    stripped from the entry; status line shows SENT TO / FAILED.
  - DELIVER: POST /api/emails resolves NAME to a member by first name
    (case-insensitive; full name if given). 404 none, 409 ambiguous (lists
    full names), 403 non-member. Emits SSE `email`, delivered ONLY to the
    recipient's stream.
  - READ (Sync): EMAIL section above chat, unread bold + "N NEW" count,
    click marks read (POST /api/emails/:id/read). Live via SSE -> refetch.
    Hover title shows the reply command.
  - COMMUNITY: sender and recipient must both hold a Sync tag (Admin, R&D,
    Usership, Onyx, Legacy) — same gate as LOT Chat, so email is a private
    lane of the same Community.
  - COHORT DATING: Cohort Connect member cards now show
    "or write /email to NAME in Log" beside "Send message" (which goes to Sync).
