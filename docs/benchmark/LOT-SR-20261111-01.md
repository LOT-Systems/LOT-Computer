### Crisis detector — design

```
MODE     high-recall regex set (kill/hurt myself, suicidal, end my life,
         want to die, better off without me, can't go on, overdose, self-harm)
WHY      false positive  → poetry swapped for plain safety language (cheap)
         false negative  → stylised reply to a person in danger (unacceptable)
SCOPE    gates tone only; not a clinical classifier; never diagnoses
NEGATIVE "this deadline is killing me", "love it to death", "cut the onions" → no flag
```
