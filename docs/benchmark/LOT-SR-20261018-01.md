DESIGN (simplest thing that satisfies the brief)
--------------------------------------------------------------------------------
- INTERNAL mail between LOT members. No SMTP, no external delivery, no new
  dependency. (Resend stays auth-only.) Mail = one table, 4 endpoints.
- COMPOSE: typing "/email to <Name>" in a Log entry opens an EMAIL block under
  the entry. First word after "to" is looked up against members' first names.
  One match -> auto-selected; several -> pick one; none -> says so.
  Block has Subject + Message + Send. Alias: /mail.
- DELIVER: mail lands in the recipient's Sync tab as a MAIL list above the
  chat stream (NEW tag, expand to read, Reply). Live via SSE `email_received`,
  sent ONLY to the addressee's connections (not broadcast).
- CHAT (Sync): same tab, same access rule, same SSE channel. Reply from Sync
  hands the sender to the Log composer.
- COHORT / COMMUNITY: Cohort Connect widget gets an "Email" button beside
  "Send message"; it hands the member to the Log composer. Cohort-initiated
  email records signal `cohort_email_initiated` for the intent engine.
- ACCESS: sender AND receiver need Sync access (Admin / R&D / Usership / Onyx /
  Legacy), not suspended. Cannot email self. Body <= 5000, subject <= 200.
- AUDIT: each send writes a Log row, event `email_sent` (ids + subject, no body).
