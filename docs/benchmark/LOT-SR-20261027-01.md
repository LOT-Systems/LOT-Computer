## 1. Mission
Simplest LOT® Email system, LOT style. Compose in Log with `/email to Hitomi.`; new mail appears in Sync; integrated with Sync chat and Cohort Dating via LOT Community.

## 2. Design (smallest thing that works)
| Piece | Decision |
|---|---|
| Storage | New `emails` table: `senderId`, `recipientId`, `body`, `source` (`log`/`sync`/`cohort`), `readAt`. No subject, threads, attachments, or external SMTP. |
| Compose | In Log type `/email to NAME.` then the message. A live `EMAIL:` block shows TO / body and a **Send** button. After send, the log text is cleared and the block shows `SENT → NAME`. |
| Read | Sync tab shows an `EMAIL · N NEW` section above chat (latest 10 received). Click marks read. |
| Delivery | Server emits SSE `email` to the recipient only; Sync refetches the inbox. |
| Community | Sender and recipient must both be LOT Community members (the Sync chat tag set: Admin/RND/Usership/Onyx/Legacy; Suspended excluded). |
| Cohort Dating | The cohort Direct Message thread has an **Email** button that sends the draft as email (`source=cohort`, recipient by user id). |
| Name resolution | Exact first name or full name, case-insensitive, among community members. 404 if none; 409 listing full names if ambiguous. |
