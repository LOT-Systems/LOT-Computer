HOW IT WORKS
--------------------------------------------------------------------------------
COMPOSE:  type `/email to Hitomi <text>` (or ✉️/📧, or /mail) in Log -> inline
          MAIL block, edit body, Send/Cancel. Name matched case-insensitively
          against LOT Community users; unknown 404, ambiguous 409, self 400.
INBOX:    Sync -> Mail tab; newest 50; unread badge; opens mark read.
LIVE:     SSE `lot_mail` delivered only to toUserId.
COHORT:   ChatCatalystWidget "✉ Mail" opens Log with the compose command
          prefilled for the cohort member (Cohort Dating via Community).
LIMITS:   plain text, no attachments, no external SMTP — in-app only by design.
OPEN:     Sync chat/mail share a tab strip only; no threading/reply yet.
          Mail is not wired into LOT Memory/Log events (unlike direct_message).
