## 6. LEXICON (new terms)

- **Register lexicon**: the word list that decides how much of each humanoid register a text carries.
- **Blanking**: removing a product or technical name before scoring, so a register word inside a name does not count.

## 7. DOCTRINE (distilled)

> **A lower number that is true beats a higher number that is noise.** The engine cannot calibrate on a register it only imagines it heard.
