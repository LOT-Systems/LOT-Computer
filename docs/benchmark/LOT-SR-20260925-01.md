OPEN TAB is live at the existing "Basics" nav button (was disabled/no-route;
now routes to /basics inside the authenticated app shell — same gating as
System/Settings/Log/Sync, not a separate anonymous entry point; true
logged-out public access would need a new unauthenticated HTML entry, out of
Month 1 scope, noted for later).

Surface intentionally breaks house rounded/Arial style: white ground, black
ink, monospace bold (Liberation Mono stack with system fallback — no font
file fetched, no network dependency), 2px black rules, square corners
(rounded-none throughout), hierarchy by inversion only (black-on-white <->
white-on-black), no color, no icons. This is a deliberate departure from
docs/technical/LOT-STYLE-GUIDE.md's rounded/opacity-hierarchy system — the
ration module reads as issued manifest, not app chrome.

line (USD 100.00/mo, recurring monthly), and the 23-item ration ledger
(nomenclature + cadence only — COGS withheld per directive, never exposed to
the client). Two StatusLine bars bookend the page: header tokens (DOC,
MODULE, STATE, MODE) and a footer registering ROSTER / UPGRADE / ISSUE as
LOCKED — M2 / LOCKED — M3, so the surface is honest that intake, billing,
and fulfillment are not yet built rather than implying they work.

No backend, no billing, no roster persistence, no auth gating change — pure
static read-only client surface, matching the MONTH 1 exit bar: "a stranger
can read what LOT issues and on what terms."
