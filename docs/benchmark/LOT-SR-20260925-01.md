05 // FEATURES — WHAT SHIPPED THIS SESSION
--------------------------------------------------------------------------------
F1 PERSONAL AFFINITY (src/shared/utils/astrology.ts)
   New getPersonalAstrologyAffinity(logs): scans a user's own Logs for the
   astroRokuyo/astroMoonPhase already stamped in each log's context, tallies
   frequency per value, and returns the rokuyo/moon-phase the user's own
   activity co-occurs with most. Below MIN_AFFINITY_SAMPLE=12 stamped logs
   it returns null — honest silence over a claim with too little data, per
   the "Honest engineering" cardinal rule. This is a plain frequency count
   of the user's own history, framed as such — not a causal or mystical
   claim.

F2 ASTROLOGY BLOCK PERSONALIZATION (src/client/components/System.tsx)
   Both Astrology block renders (the standalone dashboard block and the
   astrology/psychology/journey/quantum cycling block) now compute
   astrologyAffinity = getPersonalAstrologyAffinity(logs) and, once the
   sample floor is met, show a second line under the ambient reading:
   "Most logged on <rokuyo> days (<n>/<total>) • <moon phase> (<n>/<total>)".
   Renders nothing extra below the floor — the ambient-only reading is
   unchanged for light users.

F3 WIDGET SYNCHRONIZATION (src/client/components/QuantumSignWidget.tsx)
   The "astrology patch" shown in the widget's Patches view previously
   rotated through 4 fictional entries (Lunar Reset / Solar Return /
   Mercury Direct / Venus Transit) keyed on day-of-year — disconnected
   from the actual rokuyo/moon-phase shown elsewhere in the app. It now
   imports getRokuyo/getMoonPhase from the same #shared/utils/astrology
   module System.tsx and getLogContext use, and derives the patch name/
   description from the real current rokuyo (6-way table) and moon phase
   (8-way table). All three surfaces — System.tsx Astrology block,
   QuantumSignWidget's patch, and the Logs ASTRO stamp — now read the same
   ambient truth instead of three independent generators. Psychology patch
   left untouched (no ambient ground truth exists to synchronize it
   against; out of scope for this pass).

F4 LOGS SYNC — VERIFIED, NOT MODIFIED
   Confirmed getLogContext() → LogContext.astro* → Logs.tsx "ASTRO:" line
   is a live, already-working path from a prior session. No code change;
   recorded here because the routine explicitly asked to verify it.
