05 // ROUTINES IMPLEMENTED
--------------------------------------------------------------------------------
R1 STORY RANGES      /story now takes an optional argument: /story
                     [day|week|month|year], default day. Client extracts the
                     range from the log text (mirrors the existing /qi query-
                     capture pattern), sets loading label immediately so the
                     UI never shows a stale range during a request, and sends
                     it to POST /api/story. Server windows the Log query by
                     range (Op.gte cutoff: 1/7/30/365 days), raises the entry
                     cap and token budget per range (day: 8 entries/384
                     tokens/80-150w -> year: 80 entries/640 tokens/180-260w),
                     and rewrites the system prompt per range: day asks for
                     specifics, week for an arc, month for recurring shape,
                     year for the throughline — explicitly told to compress
                     harder, not list harder, as the window widens. Response
                     now echoes `range` so the client's Block label reads
                     "STORY [WEEK]:" etc. Realizes intake item 3 verbatim:
                     LOT User data -> QIE -> Together AI -> personalized data
                     stored, at four selectable compressions.
R2 WHITELIST FIX     'generated_story' — the event POST /api/story has
                     written to the Log table since it was built — was never
                     added to the GET /api/logs displayableEvents whitelist.
                     Every /story response was persisted and then silently
                     dropped on read: it would never re-appear if the operator
                     reloaded the Log. Exact instance of the existing Backend
                     Whitelist Hygiene doctrine clause (SR-20260604-01
                     precedent); added the missing string, cited the doctrine
                     inline as a comment so the next session doesn't relearn
                     the same lesson from scratch.
