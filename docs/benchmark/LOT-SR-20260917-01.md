--------------------------------------------------------------------------------

NEW SECTION 07 — DESIGN LOCK (BOM):
  Locks the six Section 03 component CLASSES (named 2026-07-28 without
  parameters) to build-of-one specs:
    Actuator      Linear voice-coil, 8mm stroke, 3.5N peak, ~175Hz resonance
    Reaction mass Tungsten-loaded polymer slug, 18g
    Piezo bias    Bimorph, 10° off vertical, <2ms rise, T+1ms fire delay
    IMU           6-axis, ±16g / ±2000°/s, 1kHz sample rate
    Edge sensor   Single-zone ToF, 30-200mm, 50Hz, 25° forward cone
    MCU / power   Cortex-M0+ · BLE · single-cell Li-Po 3.7V 180mAh · Qi coil
  Each parameter is derived from an existing Section 03/04 constraint
  (e.g. 1kHz IMU rate derived from needing 100+ samples inside the
  Section 03 150ms landing window) rather than picked arbitrarily.
  Shell layup and elastomer foot compound explicitly left NOT YET LOCKED
  — both need a physical sample, which does not exist.

NEW SECTION 08 — FIRMWARE STATE MACHINE + TEST PROTOCOL:
  10-state gesture-dispatch cycle: IDLE -> EDGE_CHECK -> ACTUATE ->
  BIAS_FIRE -> AIRBORNE -> LANDING -> [RECOVERY] -> TELEMETRY_EMIT ->
  COOLDOWN -> IDLE, with an EDGE_CHECK -> SHUDDER branch for the Section
  03 edge-detection safety gate. Shared by all four Section 04 gestures;
  they differ only in ACTUATE amplitude and whether BIAS_FIRE runs.
  500/500 gate (Section 06) operationalized: reference-laminate rig,
  55/30/10/5 NUDGE/HOP/LEAP/SETTLE trial mix approximating badge-rarity
  skew, four named failure classes (OFF-TABLE, TIP-RECOVERY-FAIL,
  ACTUATOR-FAULT, TELEMETRY-DROP), 500 CONSECUTIVE clean trials required
  — a failure resets the counter. Status: protocol specified, no
  physical unit exists yet to run it against.

SECTION 04 ADDENDUM — COHORT RESONANCE PING:
  Section 01 (2026-07-28) named cohort resonance ping as a trigger class
  alongside badge unlock and memory-question-ready; the Section 04 table
  never mapped it. This cycle maps it to THE NUDGE (no new gesture) —
  fires when 2+ same-cohort operators (LOT-CUBIQ-OPERATOR.md Section 05,
  Cohort Connect) cross MOMENTUM LOCK (QIE P80) within the operator's own
  24h MOMENTUM LOCK window. The gesture is deliberately indistinguishable
  from a memory-question NUDGE by feel — presence, not disclosure.
