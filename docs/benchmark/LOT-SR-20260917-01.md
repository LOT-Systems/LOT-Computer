Feature surface (unchanged from the original 2026-06-12 design — it was
already the simplest workable shape and still matched the brief exactly):
  - `/email to [Name] [body]` (or ✉️/📧) in Log opens an inline compose
    panel; sends via POST /api/mail, which resolves [Name] against LOT
    Community users (first/last name, case-insensitive).
  - Sync gains a Chat | Mail tab strip; EmailInbox lists received mail,
    unread count badges the Mail tab, GET /api/mail/inbox and
    /api/mail/unread-count back it, PUT /api/mail/:id/read clears it.
  - New mail arrives live via the existing SSE channel (`lot_mail` event),
    routed server-side only to the intended recipient.
  - ChatCatalystWidget — the Cohort Dating connection-prompt widget — gets
    a ✉ Mail button that jumps to Log with `/email to [cohort member] `
    pre-filled, closing the loop asked for: Cohort Dating → Log → Sync.
