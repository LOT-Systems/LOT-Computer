## Goal
Simplest LOT® Email: compose in Log with `/email to Hitomi.`, new messages appear in Sync, integrated with Sync (chat) and Cohort Dating via LOT Community.

## What shipped
| Layer | Change |
|---|---|
| DB | `lot_emails` table (id, senderId, receiverId, body, readAt, timestamps) — migration `20260807120000_add-lot-emails.cjs`, model `src/server/models/lot-email.ts` |
| API | `POST /api/email` (by first name `to` or `toUserId`; 404 unknown, 409 ambiguous w/ candidates, no self-mail), `GET /api/email/inbox`, `POST /api/email/read`; SSE `email` event delivered only to receiver |
| Log | `/email to <Name>. <text>` (alias `/mail`). Live EMAIL block shows draft target; **Ctrl+Enter sends**; command replaced by receipt `✉ → Name: text` (no re-send); `/system` help lists it |
| Sync | EMAIL section above chat: unread count, live SSE arrival, Reply inline, auto mark-read after 3s |
| Cohort Dating | "Email" button per cohort match → inline composer → `toUserId`; records `cohort_email_initiated` intent signal |
