01 // DESIGN — "SIMPLEST POSSIBLE"
--------------------------------------------------------------------------------
PRINCIPLE        No new table. No migration. No external mail provider.
STORAGE          A LOT® Email is a `direct_messages` row whose body starts with
                 the envelope `✉ LOT EMAIL\n` (LOT_EMAIL_PREFIX).
                 Plain DMs and letters share rails; the prefix separates them.
ADDRESSING       First name ("Hitomi"), first name + last initial
                 ("Hitomi K"), or the member's account email. Case-insensitive.
                 Ambiguous names return the candidate list (Hitomi K. · Hitomi S.).
PRIVACY          SSE `lot_email` is forwarded ONLY to sender + receiver.
                 Suspended members can't be addressed and are hidden from
                 inboxes. Self-addressing refused.
FLOOD GUARD      30 letters / sender / hour (429 beyond).
LIMIT            2000 chars per letter.

--------------------------------------------------------------------------------
02 // OPERATOR FLOW
--------------------------------------------------------------------------------
LOG              Type in the Log:
                   /email to Hitomi. Thank you for the walk yesterday.
                 or
                   /email to Hitomi K:
                   Multi-line letter on the
                   following lines.
                 A MAIL: block appears under the editor:
                   TO      Hitomi
                   BODY    37 CHARS
                   [Send]
                 On Send the command line is rewritten in place to
                   ✉ Sent to Hitomi K. · 14:32
                 and the status reads DELIVERED → HITOMI K. · 14:32 · SYNC.
                 Past log stream shows a MAIL: SENT → Hitomi K. entry.
                 /system help lists /email.
SYNC             New top section "MAIL · N NEW" above LOT Chat:
                   ● Vadik M.   Thank you for the walk…        14:32
                   → Hitomi K.  Yes. See you.                  14:40
                 Click a letter → expands full text + "To <Name>" reply field
                 (Enter sends). New letters arrive live via SSE.
                 Unread = received after last Sync visit (per-browser marker).
                 MAIL is visible to every member, including those without
                 LOT Chat access tags (chat gate unchanged).
COHORT DATING    Cohort Connect match card → new [Email] button beside
                 View profile / Send message. Opens Sync with the composer
                 addressed to that match by id (no name ambiguity).
                 Records `cohort_email_initiated` signal for the intent engine.
