## 4. DECISIONS

| # | Decision | Why |
|---|---|---|
| D1 | Env flag, exact string `on` | An accidental `true`/`1` does not switch on a voice experiment. Off is the zero-config state |
| D2 | Elevated risk skips the voice entirely | Elevated risk is not a case for steering. COSMO® would hold most self-care questions anyway (no human bridge), so skipping also saves a wasted AI call |
| D3 | HELD → regenerate with the standard prompt, not the backup bank | The person still gets a personalized question. The cost is at most one extra call, and only when the flag is on |
| D4 | Screen question **and** options | Options are text the person reads too |
| D5 | Pure surface module, flag passed in | The smoke test runs the same decision code the route runs, with no mocks |

## 6. LEXICON (new terms)

- **Surface**: the first product path where the engine's voice reaches a person. Audit `source:'surface'`.
- **Skip code**: the label that explains why the voice stayed out (`flag-off`, `no-consent`, `low-signal`, `elevated-risk`).
- **Standard path**: LOT's uncalibrated behaviour. It is always the fallback and is never degraded.

## 7. DOCTRINE (distilled)

> **When in doubt, the standard path.** The calibrated voice is a gift that has to pass four gates and COSMO®. The person never pays for a hold.
