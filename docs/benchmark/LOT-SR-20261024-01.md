## HOW IT WORKS
1. In Log type: `/email to Hitomi. Dinner at 8?` then `/send` on the same entry.
   `/send` is the explicit commit because Log autosaves while typing — a `/email` trigger alone would fire mid-sentence.
2. Result block `EMAIL:` shows `SENT TO HITOMI`, or the failure (unknown name, ambiguous name with candidate list, self-email).
3. Recipient's Sync shows the message in `Email · N new` via SSE; clicking marks it read.
4. Cohort: expand a match → `Email` → Sync opens with a `To <Name>` compose form.
5. `/system` help lists the command.
