03 // DESIGN (simplest thing that works)
One table, three routes, one command, one inbox.

  COMPOSE   Log:   /email to Hitomi. Dinner at 8?
            • Typing never sends. Ctrl/⌘+Enter sends (existing "save now" gesture).
            • Subject = first line of body (80 chars); body = everything after "to NAME".
            • Duplicate-send guard: identical text is not re-sent.
            • Result shown in an EMAIL: block (COMPOSE / SENDING / SENT / FAILED).
  DELIVER   POST /api/emails → row in `emails` → SSE 'email' event, delivered ONLY
            to the recipient's stream (receiverId check in /api/sync).
  READ      Sync: "Mail · N new" panel above the chat stream. Click to open
            (marks read), Reply pre-fills composer. Live refresh on SSE.
  RESOLVE   `to` = user id or first name (case-insensitive, community members only,
            never self). Several matches → 409 with candidates (first+last name).
