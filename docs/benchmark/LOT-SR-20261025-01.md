# LOT-SR-20261025-01 — LOT® Email v1

**Date:** 2026-10-25 · **Branch:** `claude/determined-turing-80rpgm` · **Mode:** scheduled routine

## Brief
Simplest LOT® Email: compose in Log with `/email to Hitomi.`, new messages appear in Sync, integrated with LOT Chat (Sync) and Cohort Dating via LOT Community.

## What shipped
| Layer | Change |
|---|---|
| DB | `migrations/20261025120000_add-emails-table.cjs` — `emails` (id, senderId, receiverId, body, readAt, timestamps; 2 indexes) |
| Model | `src/server/models/email.ts`, registered in `models/index.ts`; `Email` / `EmailRecord` types + `email` SyncEvent in `shared/types` |
| API | `POST /api/emails` (resolve recipient by first name or "First Last", 404 unknown, 409 ambiguous), `GET /api/emails` (inbox, 50), `POST /api/emails/read`. SSE `email` event is delivered **only** to the receiver. Logs an `email_sent` event. |
| Log | `/email to Name. message…` → live **EMAIL:** block (TO / preview / Send). Text after the dot is the body. Listed in `/system`. Only on the primary (current) log entry, so old entries can't be re-sent by accident. |
| Sync | EMAIL panel above chat: unread dot + count, click to mark read, **Reply** inline compose, live refresh via SSE. |
| Community / Cohort Dating | Cohort match cards get an **Email** button → opens the Sync composer prefilled to that member (`stores.emailComposeTo`); records `cohort_email_initiated` signal. |

## Rules
- Sender and recipient must hold a chat-eligible tag (Admin, R&D, Usership, Onyx, Legacy) = LOT Community; no self-mail.
- Body max 5000 chars. Plain text. No subject, no attachments, no external SMTP (v1 is internal mail).
