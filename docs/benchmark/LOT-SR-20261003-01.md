# LOT-SR-20261003-01 — LOT® Email v1

**Date:** 2026-10-03 · **Branch:** claude/determined-turing-t9qvy5 · **Mode:** scheduled routine

## Mission
Simplest LOT® Email: compose in Log with `/email to Hitomi.`, receive in Sync, integrate with Sync chat, Cohort Dating and LOT Community.

## Design (zero schema change)
An email is a `direct_messages` row whose body starts with `✉ ` (`src/shared/email.ts`). Reuses the existing DirectMessage model, SSE `direct_message` channel and Sync.

## Shipped
| Surface | Change |
|---|---|
| Shared | `src/shared/email.ts` — marker, `/email to NAME. text` parser, delta detector (fires once, only after Enter, needs a body) |
| Server | `POST /api/emails` (resolve recipient by first name or `toUserId`), `GET /api/emails` (inbox, 50 newest) in `routes/api.ts` |
| Log | `/email to NAME. text` + Enter sends; `EMAIL:` result block; listed in `/system` help |
| Sync | EMAIL section above chat: inbox, live refresh via SSE, reply hint |
| Cohort Dating | "Message" on a match opens Sync with an email composer addressed to that match |
| Test | `scripts/tests/test-lot-email.ts` — parser cases (passes with `node --experimental-strip-types`) |

## LOT Community rules
Sender and recipient must hold Admin / R&D / Usership / Onyx / Legacy (same tiers as Sync chat). Suspended users cannot send or receive. Ambiguous first names return 409 (use Cohort button to disambiguate); self-send rejected.

## Known limits / next
- Emails share the DM table, so they also appear in the per-user DM thread (`/direct-messages/:id`) with the `✉` prefix.
- No read/unread state, subject line, or outbound (real SMTP) mail. Candidates: `read_at` column + migration; unread badge on Sync tab; `/email` autocomplete of names.
