DESIGN (simplest thing that works)
--------------------------------------------------------------------------------
MODEL     emails(id, senderId, receiverId, body, readAt, createdAt, updatedAt).
          No subject, threads, attachments, or external SMTP. Internal mail
          between LOT Community members only.
COMPOSE   Log: type "/email to Hitomi. Dinner at 8?" -> EMAIL: block parses
          recipient + body live -> "Send email". On send the command text is
          stripped from the log. Forms: "to Hitomi." / "to Hitomi Tanaka:" /
          "to Hitomi message". Ambiguous first name -> 409, use full name.
READ      Sync: MAIL panel above Chat (inbox / sent toggle, unread dot,
          click to expand + mark read, inline Reply). Live via SSE
          `email_received` (notify only; body never goes over the shared
          channel, receiver refetches).
COMMUNITY Sender and recipient must pass the Sync chat gate (Admin, R&D,
          Usership, Onyx, Legacy); suspended users blocked both ways.
CHAT      Mail lives in Sync beside LOT Chat; same gate, same SSE channel.
COHORT    Cohort Connect "Send message" -> "Send email": sets $emailCompose
          (receiverId), navigates to Sync, composer opens pre-addressed.
SIGNAL    `email_sent` Log event written server-side, so the memory/pattern
          layer can see social outreach (consumers not yet wired).
