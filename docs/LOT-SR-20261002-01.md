## 3. BADGE ENGINE v33 — THE STOIC TERMINAL

### Theme Rationale

The Stoics ran philosophy like an operating system: load virtues at boot,
run reason as the kernel, accept what the environment delivers, and recover
coherently. Marcus Aurelius wrote private debug logs — the Meditations were
never intended for publication. Epictetus published a 53-paragraph README
for the examined life (the Enchiridion). Seneca sent API documentation
as letters to a friend.

The vocabulary they created — amor fati, memento mori, ataraxia, eudaimonia,
apatheia, logos — is not academic. It is the self-care OS vocabulary of people
who operated under extreme conditions: a slave, an emperor, a condemned man.
This is the correct register for LOT.

Word Turn v23 makes this vocabulary executable. Writing "amor fati" in your
journal runs a command. The system recognizes the input.

## 10. SELF-ASSEMBLY OBSERVATION

The v33 theme follows a natural arc from v32. The Hero's Journey (v32) names the
structure of transformation — departure, initiation, return. The Stoic Terminal
(v33) names the internal equipment needed to survive that journey: amor fati to
accept what the journey delivers, memento mori to remember what's at stake,
ataraxia as the target state, dichotomy of control as the primary diagnostic tool.

The two codices are companion volumes. Campbell mapped the external structure.
The Stoics provided the internal OS. LOT runs both simultaneously.

Word Turn v23 is the twentieth Word Turn engine (the nineteenth introduced in v32).
The pattern has held since v1: twelve badges, one theme, all triggered by the
vocabulary the user already uses to understand themselves. The Stoic Terminal
assumes the user has already encountered this vocabulary — and routes it back
to them as a self-care signal.

The COSMIC badge `twenty_three_registers` requires one badge from all 23 engines.
It is a credential for running every vocabulary the LOT system has defined.
Water through Stoic. The archive of every language the self has ever needed.
