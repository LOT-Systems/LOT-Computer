## 1. TASK

Build a hardware computer connected to lot-systems.com, covering the plan, a components buying
list with links, and a roadmap analysis. The device is a 40×40×5 mm two-part stainless square.

- One side is polished steel.
- The other side has a screen, a camera and a COPY button. COPY sends a signal back to the Log tab.
- It shows pager-like autonomous notifications.
- It has a weather sensor and AI-grade off-the-shelf sensors, and charges wirelessly.
- Fabrication goes through PCBWay, for a 100-unit run.
- Outputs: firmware and software, separate documents, PDF manuals, compressed per-session state, and an .MD report every session.

## 3. KEY DECISIONS

```
D-01  Wireless charging through steel     → Ø18 mirror zirconia inlay in the back + matched LOT puck (Qi)
D-02  Radio                               → ESP32-S3-MINI-1 pre-certified module (avoids $10–20k FCC)
D-03  Screen                              → Sharp memory LCD 128×128: reflective silver, ~0 µW static
D-04  AI-grade sensors                    → BME688 (BSEC2 AI gas/IAQ), BHI260AP (self-learning IMU), camera
D-05  Server integration for EVT-0        → zero server change: existing /api/contextual-prompts,
                                            /api/live-message, POST /api/logs (event 'note')
D-06  Session compression                 → 00-STATE-CAPSULE.md (program) + lot::compress ≤64 chars (device)
```

## 4. ANALYSIS: what will bite

1. **5.0 mm is over budget on paper (5.10 mm).** The realistic EVT-1 thickness is 5.4–5.8 mm. The ways to recover it are listed in 03 §01.
2. **Solid steel blocks both Qi and Wi-Fi.** The inlay plus the front-glass antenna aperture solve this, but it must be proven on the bench in P1.
3. **Battery life vs immediacy.** With an 85 mAh cell, pager mode (15-min poll) lasts about 9–10 days. Instant mode lasts about 2 days.
4. **Credential.** EVT-0 uses the account's `auth_token` JWT, which is acceptable only on test accounts. EVT-1 needs scoped device tokens, which is a server change.
5. **Cost.** Estimated at $158–214 per unit. RUN-100 is about $20–32k including certification.
