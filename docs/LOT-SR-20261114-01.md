## BUILD

### 1. Spec — `docs/technical/LOT-USERSHIP-12-MONTH-EVOLUTION.md`

Main points:

- **Four evolution signals:** S1 journal (`note`), S2 Memory answers, S3
  morning check-ins, S4 self-care completions. Only deliberate acts unlock
  months; time alone never does.
- **Months unlocked gate:** per 30-day window, `unlocked` = 3 of 4 signals at
  Base and `sealed` = 4 of 4 at Full. Thresholds rise each chapter.
  Quiet months are never punished and can be re-opened by sealing the next
  month.
- **Narrative spine:** the 12 stages of the Hero's Journey map onto the 12
  months, grouped into 4 Chapters (Foundation / Structure / Depth /
  Integration). This reuses the v32 Codex vocabulary.
- **The Usership Dial:** 12 month badges + 4 chapter seals drawn from the
  existing Water and Architecture glyph themes:
  `∘ ∘∘ ∘∘∘ ├─ ╞═╡ ◐ ≈ ≋ ║·║ ◎ ◉· ◉` and seals `◇ ◈ ◆ ⊙`.
- **Compression ladder (core deliverable):** Logs → Weekly Story →
  **Memory Capsule** (12 paragraphs) → **Chapter** (4) → **The Year** (1
  paragraph + 12 one-liners). Text gets shorter at each step up and says more,
  so the person can see the compression. The spec includes a capsule prompt
  contract, a payload schema, and the register by EvolutionScore.
- **Month by month:** each month has the same seven parts (stage, system state,
  unlocks, Month widget copy, Memory deliverable, badge, public profile layer).
  Barebone Month 1 grows to LOT® AI at Month 12.
- **Widgets:** `Month n:` → `Unlocked:` → `Next:` · Memory `Capsule:` /
  `Story:` · ambient `Months unlocked: n/12`.
- **Public profile:** one layer added per month, reaching section parity with
  `/u/machiavelli` at Month 12. A proposed `usershipJourney` type is included.
- **Roadmap P0–P5** and **5 open questions for S-2**.
