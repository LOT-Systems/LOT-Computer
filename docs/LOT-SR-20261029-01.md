## DESIGN (the simplest thing that works)

| Piece | Decision |
|---|---|
| Storage | One table `emails` (sender, receiver, optional subject, body, source, readAt). No threads, folders, attachments, or external SMTP. |
| Compose | In **Log**: `/email to Hitomi. Message text` then **Ctrl+Enter** sends. Recipient ends at first `.` `:` `,` or newline; up to two words (`Hitomi Tanaka`). |
| Safety | Send fires only on explicit Ctrl+Enter (autosave never sends a half-typed mail). After send the command is rewritten in the log to `✉ Email sent to X: …`, so it cannot be re-sent. |
| Delivery | Receiver-only SSE event `email` → appears live at the top of **Sync**; also loaded via `GET /api/emails` (last 50). Click to mark read. |
| Community | Sender and receiver must both be LOT Community (same gate as Sync chat: Usership / Onyx / Legacy / R&D / Admin); suspended users excluded. Name lookup is case-insensitive on first name; ambiguous names return 409 with candidates. |
| Cohort | Cohort Connect cards get an **Email** button → opens an inline compose line in Sync addressed by user id (no ambiguity). Emits `cohort_email_initiated` signal. |
| Log trail | Server writes an `email_sent` log event (metadata only, no body). |
