## 3. How it works
1. In Log type `/email to Hitomi. See you at 5` (also `:`/`,`/newline after the name; `Hitomi Tanaka` for disambiguation; `/mail` alias).
2. Press **Ctrl/Cmd+Enter**. Sending is explicit — typing the command never sends (the trigger effect fires on keystrokes, so auto-send would have mailed half-written text).
3. Server resolves the name among **LOT Community members** (Admin / R&D / Usership / Onyx / Legacy, non-suspended), 404 if none, 409 if ambiguous.
4. Recipient's Sync shows the mail instantly via SSE; click marks it read.
5. Sender logs an `email_sent` event (feeds the intention engine like `direct_message_sent`).

## 4. Community integration
Same gate as Sync chat on both ends. Name lookup is limited to members, so it can't be used to probe for accounts outside Community.
