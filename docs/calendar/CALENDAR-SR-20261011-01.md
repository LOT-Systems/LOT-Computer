# CALENDAR WIDGET — SESSION REPORT 2026-10-11 #01

**Class:** ENGINEERING · **Branch:** `claude/dreamy-babbage-erad2g` · **Trigger:** scheduled routine

## Goal
Reliable Calendar widget that tracks time and writes to Log, with terse military-style alerts. UI stays minimalist.

## Baseline
`CalendarWidget.tsx` was date-only: no time, no alerts, no entry ids; only `calendar_entry` logs.

## Changes
| File | Change |
|---|---|
| `src/client/utils/calendar.ts` (new) | Pure timing logic: `dueMs`, `currentStage`, `formatCountdown`, `alertKey`, `compareEntries`, `isValidTime`. Stages **T-15 → T-05 → T-00 → LATE(MISSED)**; stale after 6h. |
| `CalendarWidget.tsx` | Optional `HH:mm` time input; entries carry log id + time; 15s clock tick (paused on hidden tab, resync on return); alert banner (mono, uppercase, pulse at T-00, dim for MISSED); each (entry, stage) fires once, dedup via localStorage **and** persisted `calendar_alert` logs (cross-device); countdown `T-14:59`. |
| `CalendarWidget.tsx` (bugfix) | `getMonthWeeks` overflowed on days 29–31 (`.month()` set before `startOf`), showing the wrong month. Fixed. |
| `Logs.tsx` | Renders `calendar_alert` as `ALERT: T-05 · CALL` + date/time. |
| `api.ts` | `calendar_alert` added to displayable `/logs` events. |

Log format: `[ALERT T-05] CALL 14:30 — text`, metadata `{entryId, stage, date, time, entryType}`.

## Verification
- Pure logic: 15 assertions (stage boundaries, stale cutoff, invalid time/date, countdown formats) — PASS via `tsx`.
- `esbuild` parse of CalendarWidget.tsx and Logs.tsx — PASS.
- **Not run:** full `tsc` / app build (no `node_modules` in this environment), no browser test.

## Known limits / next
- Alerts fire only while the System page is open (client-side). Reliable background delivery needs a server job or Web Push / `Notification` API.
- If `createLog` fails, that stage is marked fired locally and not retried.
- Banner has no manual dismiss/ack yet; MISSED lingers up to 6h.
- Edit/delete/complete for entries; optional recurring entries.
- Add a unit-test runner (repo has none) for `calendar.ts`.
